# claw-trade 升级操作指南

## 一句话

升级流程是：

```text
发布机制作签名生产包 -> 上传到七牛 stable/ -> 刷新七牛 CDN -> 目标机在 claw-trade 设置页检查并安装更新
```

第一版远程升级不需要自建后台服务器，但需要一个 HTTPS 可访问的对象存储目录。当前使用七牛对象存储。

升级的是 claw-trade 应用，不是 Ubuntu 系统。它不执行系统升级，不重装 Ubuntu，不改内核、驱动、分区或系统包。

## 1. 在发布机制作升级包

进入仓库：

```bash
cd /home/frank/src/claw-trade
git status
```

确认代码在 `main`，并且需要发布的改动已经提交。

构建生产包：

```bash
scripts/production/build_production_package.sh
```

构建完成后会生成类似：

```text
dist/production/claw-trade-production-0.1.4-20260628T171737Z.tar.gz
dist/production/claw-trade-production-0.1.4-20260628T171737Z.tar.gz.sha256
```

包名里的版本号来自 `pyproject.toml`。

## 2. 给升级包签名

发布私钥只放在发布机，不要放到目标工控机。

给生产包签名：

```bash
openssl pkeyutl -sign \
  -inkey update-signing-private.pem \
  -rawin \
  -in claw-trade-production-版本.tar.gz \
  -out claw-trade-production-版本.tar.gz.sig
```

生成 `manifest.json`：

```json
{
  "product": "claw-trade",
  "channel": "stable",
  "version": "0.1.4",
  "arch": "linux-x86_64",
  "archive": "claw-trade-production-0.1.4-20260628T171737Z.tar.gz",
  "sha256": "这里填生产包 sha256",
  "created_at": "2026-06-28T17:17:37Z",
  "min_current_version": "0.1.0",
  "notes": "release note"
}
```

字段说明：

```text
version             新版本号，必须高于目标机当前版本
archive             生产包文件名，只能是文件名，不能带路径
sha256              生产包 sha256
min_current_version 允许升级的最低当前版本
```

给 `manifest.json` 签名：

```bash
openssl pkeyutl -sign \
  -inkey update-signing-private.pem \
  -rawin \
  -in manifest.json \
  -out manifest.json.sig
```

最终要上传 4 个文件：

```text
manifest.json
manifest.json.sig
claw-trade-production-版本.tar.gz
claw-trade-production-版本.tar.gz.sig
```

## 3. 上传到七牛

上传到七牛对象存储的 `stable/` 目录。

目标路径：

```text
stable/manifest.json
stable/manifest.json.sig
stable/claw-trade-production-版本.tar.gz
stable/claw-trade-production-版本.tar.gz.sig
```

上传顺序必须是：

```text
1. 先上传 claw-trade-production-版本.tar.gz
2. 再上传 claw-trade-production-版本.tar.gz.sig
3. 再上传 manifest.json
4. 最后上传 manifest.json.sig
```

不要先上传 `manifest.json`。否则目标机可能先看到新清单，但升级包还没传完。

## 4. 刷新七牛 CDN

上传后，在七牛控制台刷新这 4 个 URL：

```text
http://thaef8z8g.hn-bkt.clouddn.com/stable/manifest.json
http://thaef8z8g.hn-bkt.clouddn.com/stable/manifest.json.sig
http://thaef8z8g.hn-bkt.clouddn.com/stable/claw-trade-production-版本.tar.gz
http://thaef8z8g.hn-bkt.clouddn.com/stable/claw-trade-production-版本.tar.gz.sig
```

刷新后等一会儿，再打开或下载：

```text
http://thaef8z8g.hn-bkt.clouddn.com/stable/manifest.json
```

确认显示的是新版本。

## 5. 目标机首次配置

目标机只保存更新源 URL 和更新公钥。目标机不能保存签名私钥，也不能保存七牛写权限密钥。

配置更新源：

```bash
sudo mkdir -p /opt/claw-trade/shared/config
sudo tee -a /opt/claw-trade/shared/config/claw-trade.env >/dev/null <<'EOF'
CLAW_TRADE_UPDATE_BASE_URL=http://thaef8z8g.hn-bkt.clouddn.com/stable/
CLAW_TRADE_AUTO_UPDATE_INSTALL=1
EOF
```

安装更新公钥：

```bash
sudo install -d -m 0755 /etc/claw-trade
sudo install -m 0644 update-signing-public.pem /etc/claw-trade/update-signing-public.pem
```

重启服务：

```bash
sudo systemctl restart claw-trade-control.service claw-trade-ui.service
```

## 6. 在 claw-trade 界面操作

打开设备界面：

```text
http://目标机IP:5175/
```

进入：

```text
设置 -> 远程更新
```

手动升级：

```text
1. 点击 检查更新
2. 看到发现新版本
3. 点击 安装更新
4. 等待服务重启
5. 刷新页面确认更新状态
```

如果配置了：

```text
CLAW_TRADE_AUTO_UPDATE_INSTALL=1
```

系统也会自动检查并安装更新。

## 7. 失败和回滚

升级安装时，目标机会校验：

```text
manifest 签名
生产包 sha256
生产包签名
包名和目录结构
版本是否高于当前版本
```

校验失败不会安装。

安装后如果服务健康检查失败，会回滚到上一版本。

如果主 UI 起不来，会进入救援页。救援页仍然使用同一个地址：

```text
http://目标机IP:5175/
```

## 8. 恢复出厂设置

界面位置：

```text
设置 -> 恢复出厂设置
```

恢复出厂只清空 claw-trade 应用状态，包括：

```text
应用配置
报告
缓存
队列
会话
临时文件
```

恢复出厂会保留：

```text
Virbox 授权
更新包
当前版本
上一可用版本
更新公钥
```

恢复出厂不是重装 Ubuntu，也不会清空整机磁盘。

## 9. 常见问题

### 检查更新提示未配置

检查目标机是否配置：

```bash
grep CLAW_TRADE_UPDATE_BASE_URL /opt/claw-trade/shared/config/claw-trade.env
```

### 检查更新提示公钥不存在

检查：

```bash
ls -l /etc/claw-trade/update-signing-public.pem
```

### 七牛已经上传，但目标机还是旧版本

先刷新七牛 CDN，再确认这个 URL 内容已经变成新版本：

```text
http://thaef8z8g.hn-bkt.clouddn.com/stable/manifest.json
```

### 安装更新按钮不可用

先点 `检查更新`。只有检查到可安装新版本后，`安装更新` 才可用。
