# 工控机硬件配置说明

日期：2026-06-27

## 结论

第一版工控机最低配置按“能稳定跑生产样机”定义，不按“Ubuntu 能开机”定义。

最低可接受配置：

```text
CPU：x86_64，4 核 / 4 线程以上，支持 AVX 或 AVX2
内存：8GB RAM
磁盘：80GB SSD
系统：Ubuntu 22.04 或 24.04 x86_64，systemd 可用
网络：可访问 Virbox 授权服务、模型服务和数据服务
```

推荐量产配置：

```text
CPU：Intel Core i3-1215U 或以上
内存：16GB RAM
磁盘：128GB SSD
系统：Ubuntu 24.04 x86_64
```

更稳配置：

```text
CPU：Intel Core i5-1235U 或以上
内存：16GB-32GB RAM
磁盘：256GB SSD
```

## CPU 要求

硬性要求：

- x86_64，不接受 ARM。
- 4 核 / 4 线程以上。
- 支持 AVX 或 AVX2 指令集。
- 最高睿频建议不低于 3.0GHz。
- 长期功耗释放建议不低于 15W；低功耗 N100 只能算最低成本方案。

推荐型号：

- 最低成本：Intel N100，4 核 4 线程，必须实机确认 AVX/AVX2 和 MongoDB 可启动。
- 推荐量产：Intel Core i3-1215U 或以上。
- 更稳：Intel Core i5-1235U 或以上。

不建议采购：

- Intel J1900。
- Intel J4125。
- Intel N5095。
- Intel N5105。
- 其它不支持 AVX 的老款赛扬、奔腾、凌动平台。

原因：项目当前使用本地 MongoDB 8.0.12。老 CPU 即使是 x86_64，如果没有 AVX，MongoDB 可能直接启动失败。

CPU 预检命令：

```bash
lscpu | grep -i avx
```

如果没有任何 `avx` 或 `avx2` 输出，这台机器不合格。

## 内存要求

硬性要求：

- 最低 8GB RAM。
- 不接受 4GB。
- 系统可用内存建议不低于 7GB。

推荐：

- 正式交付使用 16GB。
- 若报告保留时间较长、历史数据包较多或浏览器长期运行，优先 16GB-32GB。

内存类型：

- DDR4、DDR5、LPDDR4x、LPDDR5 均可。
- DDR4-2666 以上即可，DDR4-3200 或 DDR5/LPDDR5 更好。
- ECC 不强制。
- 双通道不强制。
- 优先选择可扩展内存，不优先选择板载 8GB 且不可扩展的型号。

内存预检命令：

```bash
free -h
```

## 磁盘要求

硬性要求：

- 最低 80GB SSD。
- 不接受机械硬盘作为系统盘。
- 不建议 64GB。

推荐：

- 正式交付使用 128GB SSD。
- 如果要长期保留报告、日志、诊断包、更新回滚包和多市场历史数据，建议 256GB SSD。

磁盘需要承载：

- Ubuntu 系统。
- claw-trade release 包。
- `/opt/claw-trade/shared` 运行期配置、数据、日志、报告和更新包。
- MongoDB 数据目录。
- A 股和 CRYPTO 历史 seed 数据。
- 至少一个上一版本 release 用于回滚。

磁盘预检命令：

```bash
df -h /
lsblk -o NAME,MODEL,SIZE,TYPE,ROTA
```

`ROTA` 为 `1` 通常表示机械盘，不建议用于正式交付。

## 系统和端口要求

系统要求：

- Ubuntu 22.04 或 24.04 x86_64。
- systemd 可用。
- Chromium 或等价 kiosk 浏览器可安装。
- Python 3.12 可用。

端口要求：

```text
27017：MongoDB
1933：OpenViking
18789：OpenClaw gateway
5175：Research UI
```

端口预检命令：

```bash
ss -ltnp | grep -E ':27017|:1933|:18789|:5175' || true
```

正式安装前这些端口不应被其它服务占用。

## 采购口径

最低采购口径：

```text
Intel N100 或同级以上 CPU，x86_64，4 核以上，支持 AVX/AVX2；
8GB RAM；
80GB SSD；
Ubuntu 24.04 x86_64；
有线网口；
支持 7x24 小时运行。
```

推荐采购口径：

```text
Intel Core i3-1215U 或以上 CPU，支持 AVX/AVX2；
16GB RAM；
128GB SSD；
Ubuntu 24.04 x86_64；
有线网口；
支持 7x24 小时运行。
```

禁止采购口径：

```text
不接受 ARM 平台；
不接受 4GB 内存；
不接受 64GB 或更小系统盘；
不接受无 AVX 的老款 J1900/J4125/N5095/N5105 平台；
不接受机械硬盘作为系统盘。
```

## 验收命令

到货后先跑：

```bash
uname -m
lscpu | grep -i avx
free -h
df -h /
lsblk -o NAME,MODEL,SIZE,TYPE,ROTA
```

最低通过标准：

```text
uname -m 输出 x86_64
lscpu 能看到 avx 或 avx2
内存不少于 8GB
根分区可用空间不少于 50GB，正式交付建议不少于 80GB
系统盘是 SSD
```

最终通过标准仍以生产包 preflight、MongoDB 启动、OpenViking health、OpenClaw gateway health、Research UI health 和真实 `/report` 验收为准。
