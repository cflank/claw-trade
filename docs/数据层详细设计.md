# 数据层详细设计

状态：目标详细设计。本文只写当前目标和当前允许实现，不保留旧入口说明。

## 1. 目标详细设计

目标是一个统一数据层：

- 上层提交业务数据项请求。
- 数据层内部转换为 DataNeed。
- 数据层根据接口能力目录生成 ProviderCallSpec。
- Scheduler 控制合并、限流和任务预算。
- Fetch 只执行 planner 允许的真实接口。
- Ingest 写入 raw、normalized、attempt 证据。
- DataResult 返回数据或真实缺口。

## 2. 核心合同

### 公开数据请求

公开数据请求描述 worker/tool 要什么业务数据：

- item
- market
- instrument
- time range
- granularity
- requested_by_worker
- purpose
- deadline_at

公开数据请求不包含 provider、path、api_name、url、header、token、api_id、内部需求类型字段、fields 或 字段覆盖声明。

### DataNeed

DataNeed 是数据层内部规范化模型：

- market
- instrument
- api_id
- time range
- granularity
- requested_by_worker
- purpose
- deadline_at

DataNeed 不作为 worker/tool 输入，不包含 provider、path、api_name、url、header、token。

### ProviderCallSpec

ProviderCallSpec 只能由 planner 从接口目录生成。

它包含真实出网所需信息：

- provider_id
- catalog_endpoint_id
- official_path_or_api_name
- params
- auth_scope
- rate_limit_bucket
- parser_status
- deadline_at
- need_ids

### DataResult

DataResult 返回：

- rows
- dataset_refs
- raw_refs
- attempt_refs
- gaps
- freshness

## 3. 当前删除的旧入口

以下对象不再属于当前数据层运行合同：

- `DataAPI.get_data`
- `DataAPI.get_data_batch`
- `DataService.get_data`
- `DataService.get_data_batch`
- 旧远端组装链路

## 4. 内部仓库读取

内部仓库读取入口：

```text
DataService.read_warehouse_batch(...)
```

用途：

- report 先查本地 seed。
- select 查本地列式/标准化缓存。

限制：

- 只读仓库。
- 不出网。
- 不选择 provider。
- 不补远端数据。

远端补数必须重新提交业务数据项请求。

## 5. 接口能力目录

每个接口记录：

- source_type
- endpoint_id
- official path 或 SDK method
- request method
- 参数模板
- auth_scope
- rate_limit_bucket
- http_visibility
- parser_status
- outputs
- doc_ref

outputs 必须写清能力编号。planner 只用能力编号和市场/品种/权限/可用性选择接口。

## 6. Provider 尝试顺序

同一需求按以下顺序尝试：

1. 已配置密钥的付费源。
2. 官方免费源。
3. 内置公共源。
4. 其它可用兜底源。

执行顺序按来源成组，不允许不同来源交错执行。同一来源内的多个互补接口可以连续执行；该来源满足需求后，不再调用低优先级来源。

一个结果是否满足需求，看项目精确业务数据编号 `public_api_id` 和字段/质量校验，不看 `data_type` 名字是否刚好等于项目编号后缀。`data_type` 是标准化存储类型，不是 provider 选择白名单。

失败接口保留 attempt 证据。`planned_calls` / `scheduled_calls` 可以包含未执行的候选；真实调用只看 attempt 证据。

## 7. 事件结构化

事件类接口必须提供结构化输出。

事件类包括：

- 新闻
- 公告
- 研报
- 政策
- 宏观日历
- 经济发布
- 项目公告
- 互动问答

最低字段：

- `event_id`
- `source_type`
- `event_type`
- `title`
- `published_at` 或 `event_date`
- `instrument`
- `market`
- `url`
- `summary`
- `raw_ref`

如果 raw 成功但 parser 未覆盖，DataResult 必须返回 parser_missing 缺口。

## 8. 合并

合并键必须包含真实接口身份。

禁止跨以下边界合并：

- 不同 provider。
- 不同 catalog endpoint。
- 不同 Tushare api_name。
- 不同 Coinglass path。
- 不同 auth_scope。
- 不同 rate_limit_bucket。
- SDK 内部不可见 HTTP。

## 9. 限流

限流以真实来源为桶。

例子：

- `ratelimit:tushare`
- `ratelimit:coinglass`
- `ratelimit:finnhub`
- `ratelimit:fred`
- `ratelimit:glassnode`
- `ratelimit:coingecko_pro`

要求：

- 滑动窗口。
- 任意连续窗口内不超过配置值。
- 配置值来自设置。
- structured provider 和 official raw call 共用同一桶。
- 等待超过 deadline 时返回 rate_limited_by_tool_budget。

## 10. 证据模型

成功：

- raw_payloads 写原始响应。
- normalized_datasets 写结构化数据。
- provider_attempts 写调用证据。

失败：

- provider_attempts 写失败证据。
- DataResult.gaps 写真实缺口。

## 11. Mongo Collection

授权 collection：

- `normalized_datasets`
- `raw_payloads`
- `provider_attempts`
- `provider_rate_limits`
- `single_flight_calls`
- `provider_result_cache`
- `dataset_manifests`
- `maintenance_jobs`

## 12. 缺口原因

允许的主要缺口：

- credential_missing
- permission_denied
- provider_empty
- provider_error
- parser_missing
- catalog_match_missing（兼容内部原因码；对外含义是“项目数据项未绑定可调用接口”）
- resolver_mapping_missing
- rate_limited
- rate_limited_by_tool_budget
- warehouse_missing
- warehouse_stale
- evidence_write_failed
- sdk_http_unknown

缺口不能因为“没登记给某 worker 用”产生。

## 13. Worker 边界

worker 只能看见数据工具。

工具 schema 禁止包含：

- provider
- path
- api_name
- url
- header
- token

## 14. SDK 风险

SDK 内部 HTTP 不可见时，必须登记风险。

登记内容：

- provider
- endpoint
- http_visibility
- 是否能迁移到 managed_http
- 子请求限流是否可证明
- live 证据路径

## 15. 失败含义与停止条件

停止条件：

- 新增 provider 范围限制。
- 新增业务过滤表。
- worker 传 provider/path/api_name。
- 新增 Mongo collection。
- 缺口被吞掉。
- raw 成功但结构化失败却标记为完整成功。
- 限流绕过共享桶。

## 17. 验收测试

必须覆盖：

- DataAPI 不暴露 get_data / get_data_batch。
- DataService 旧远端链路不存在。
- worker payload 不含 provider/path/api_name/url/header/token。
- 同一 DataNeed 在 report/select/ui_probe/maintenance 下候选一致。
- fields/字段覆盖声明 不否决 provider。
- 不同真实接口不能合并。
- 同源限流共享滑动窗口。
- 事件 raw 成功但 parser 缺失时返回 parser_missing。
