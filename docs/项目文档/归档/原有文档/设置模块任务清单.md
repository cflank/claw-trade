## 统一验证纪律（含 live/fresh/provider 命令）

- 任何任务的必跑命令只要包含 `scripts/start-control-runtime.sh -- <command>`，执行前必须先输出本次 runtime profile，并记录 fixed runtime preflight 表（`runtime.env`、`1933`/`18789` 健康、关键环境变量 unset/指向约束）证据；缺任一项视为 live 证据无效。
- live/fresh/provider 命令必须走 `scripts/start-control-runtime.sh -- <command>`；不得用手工分别拉起服务替代。
- `rg`、静态源码扫描、静态 render、日志拼接只能当辅助线索，不能替代真实 UI 可访问文本、真实截图、真实状态或真实运行证据。
- 所有 live 失败按 collect-first 记录失败原因、terminal stage、证据路径和根因分组；除非命中 AGENTS 允许的 early-stop 例外。

### S-01 报告模型就绪状态与 `/report` 硬阻断

- ID：S-01
- 类型：AFK
- 目标：建立真实的报告模型配置、测试、状态和报告生成阻断链路；保存配置不得等同于测试通过。

- 禁止改动范围：不改 worker DAG、prompt、PM/exporter、runtime guard；不改 OpenClaw source；不新增默认模型 fallback；不新增 profile/default market/default currency 设置。
- 依赖任务：无
- 验收标准：未配置、已保存未验证、测试失败三种状态均阻断报告；只有真实测试通过进入可用；测试失败显示可操作错误；用户配置优先；测试失败不切默认模型。

- 反向验证：证明“只保存配置”不能生成报告；证明模型测试失败不会切默认模型；证明 UI/日志没有“默认模型已自动启用”类文案。
- mock / fake / stub / fallback 检查：不允许假测试成功、假 provider 结果、默认模型兜底、capture-only 成功；live 证明必须来自真实 runtime。
- Stop conditions：需要改 OpenClaw 非通用 runtime seam；真实模型测试无法接通且没有根因；同一 gate 连续两次修复后仍失败。
