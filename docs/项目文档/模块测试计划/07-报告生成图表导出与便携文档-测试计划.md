## 6. Live 验收

需要：

- 完整 `/report` live run。
- final report 存在。
- worker appendix 存在。
- 图表资产存在或有缺失原因。
- PDF runtime capability 检查。
- 真实 PDF bytes 校验。

## 7. 停止条件

- 从本地审计副本读取正式报告材料。
- Markdown 改后缀冒充 PDF。
- PM 结论被导出层改写。
- 图表缺失却声称 ready。
