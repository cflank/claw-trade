# 标的解析模块测试计划

## 1. 测试目标

证明用户输入的标的在进入 `/report` 或 selection handoff 前被正确解析，错误不会被隐藏，也不会生成伪公司身份。

## 2. 单元测试

覆盖：

- A 股代码解析。
- 美股代码解析。
- 港股代码解析。
- CRYPTO 交易对解析。
- market hint 和代码冲突。
- 空输入、非法字符、大小写归一。
- 公司名缺失时安全占位。

建议位置：

```text
tests/unit/
```

## 3. 合同测试

覆盖：

- `RunRequest` 中 market/profile 与解析结果一致。
- HK/CRYPTO 不 fallback。
- selection handoff 必须再校验标的身份。
- UI 用户 DTO 不暴露 resolver 内部错误对象。

相关现有测试方向：

```text
tests/contracts/test_multi_market_fields.py
tests/contracts/test_profiles_contract.py
tests/contracts/test_select_report_boundary_notice.py
tests/contracts/test_selection_command_contract.py
```

## 4. 集成测试

覆盖：

1. UI 输入 A 股代码创建报告任务。
2. UI 输入 CRYPTO 候选确认转报告。
3. 错误 market + ticker 返回用户可读失败。
4. 公司名查不到时不伪造名称。

## 5. 停止条件

- 代码无法确定 market/profile。
- 只能靠默认 profile 让请求继续。
- 公司名缺失被伪装成真实名称。
- selection handoff 绕过二次校验。
