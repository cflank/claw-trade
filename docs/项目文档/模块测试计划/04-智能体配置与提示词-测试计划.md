# 智能体配置与提示词模块测试计划

## 1. 测试目标

证明 agent 配置完整、profile 正确、stage policy 缩窄工具、prompt 不泄漏内部协议，并且 worker 声线符合 TradingAgents / TradingAgents-CN 方向。

## 2. Workspace 测试

覆盖：

- 报告链路 worker 必需文件存在。
- 非报告 agent 按自己的合同校验。
- prompt profile 存在。
- skills manifest 存在。

相关测试：

```text
tests/contracts/test_all_worker_workspaces.py
tests/contracts/test_workspace_contract.py
```

## 3. Stage policy 测试

覆盖：

- worker stage 与 `STAGES.yaml` 一致。
- visible tools 等于 registry 解析结果。
- 下游纯 reasoning worker 不暴露不应有工具。

相关测试：

```text
tests/contracts/test_stage_policy_contract.py
tests/contracts/test_stage_tool_policy_contract.py
tests/contracts/test_visible_tools_guard.py
```

## 4. Prompt boundary 测试

覆盖：

- provider payload 不含 OpenViking URI/hash/protocol。
- worker prompt 不含 debug envelope。
- report worker chat prompt 不泄漏内部字段。
- CN_A prompt 对齐 policy。
- CRYPTO truthfulness prompt 不压制合法表达。

相关测试：

```text
tests/contracts/test_worker_prompt_alignment_policy.py
tests/contracts/test_prompt_alignment_cn_a_workers.py
tests/contracts/test_worker_provider_payload_no_provider_leak.py
tests/contracts/test_report_worker_chat_prompt_boundary.py
tests/contracts/test_crypto_prompt_truthfulness.py
```

## 5. Runtime proof

Prompt alignment 最终证明需要：

1. fresh live run。
2. provider final prompt。
3. worker LLM output。
4. baseline prompt/source 对比。
5. 同一 run/dispatch 的三层材料链。

## 6. 停止条件

- HK/CRYPTO 缺 profile 却 fallback。
- Prompt 中出现 RuntimeTarget/OpenViking protocol。
- Python 生成 worker 投资观点。
- Debate worker 被改成无立场 memo。
- Truthfulness guard 被扩展成风格 guard。
