# 主分支变更测试方案

范围：本地主分支相对远端主分支新增的功能。当前只测三件事：加密市场选币、价格提醒定时扫描、worker 追问。顺带测被它们影响的报告入口、报告阅读和启动脚本。

不测：全市场完整回归、所有数据源覆盖、所有历史报告兼容。那些放到全面人工测试里。

## 通过标准

1. 用户从界面能完成主流程，不靠直接调函数冒充成功。
2. 后台证据能证明真实跑过，不接受假数据、mock、stub、手填结果。
3. 普通用户页面不露内部协议、路径、token、hash、Mongo、OpenViking、provider payload。
4. 加密选币和价格提醒失败时，页面说清楚人能懂的原因，不假装完成。
5. 新增和改动的自动测试必须通过。

## 测试前准备

1. 切到主分支待测提交。
2. 启动固定运行环境：

```bash
scripts/start-control-runtime.sh
```

3. 确认服务健康：
   - OpenViking：`1933`
   - OpenClaw gateway：`18789`
   - 研究界面能在浏览器打开

4. 用真实 Chrome 操作界面。自动代测也必须用真实 Chrome 控制，不用 headless 浏览器代替。

## 一、加密市场选币

### 1. 命令入口

| 用例 | 操作 | 期望 |
|---|---|---|
| 默认选股 | 输入 `/select` | 走 A股选股，不变 |
| A股显式入口 | 输入 `/select 1`、`/select CN_A`、`/select A股` | 都走 A股选股 |
| 加密入口 | 输入 `/select 2`、`/select CRYPTO`、`/select 加密` | 都走加密市场选币 |
| 加密刷新 | 输入 `/select 2 refresh` | 强制刷新加密候选缓存 |
| 非命令文本 | 输入 `select 2` | 只当普通聊天，不触发选币 |
| 不支持市场 | 输入 `/select US`、`/select 3` | 明确提示不支持，不创建选币流程 |

### 2. 数据读取

| 用例 | 操作 | 期望 |
|---|---|---|
| 有本地加密历史 | 保证列式历史仓库存在后跑 `/select 2` | 能读取 spot USDT 日线，生成候选缓存 |
| 没有本地加密历史 | 临时让历史仓库不可用后跑 `/select 2` | 明确提示加密历史不可用，不生成假候选 |
| 历史不足 | 使用历史天数不足的数据 | 被剔除或提示缺口，不凑数 |
| 候选缓存 | 打开选币结果 | 标题和文案写“加密市场/标的”，不写“A股/股票/股价/候选股” |

### 3. 四个选币 worker

| 用例 | 操作 | 期望 |
|---|---|---|
| 策略评审 | 跑完整 `/select 2` | strategist 只基于候选池说支持理由 |
| 反方评审 | 跑完整 `/select 2` | skeptic 只指出风险和不确定性，不编缺失数据 |
| 综合排序 | 跑完整 `/select 2` | manager 给出分组，不新增候选池外标的 |
| 最终三分类 | 跑完整 `/select 2` | portfolio manager 只输出“进入 /report / 观察 / 放弃”三类 |
| 完整覆盖 | 检查最终三分类 | 候选池每个标的都且只出现一次 |

### 4. 用户确认转报告

| 用例 | 操作 | 期望 |
|---|---|---|
| 不自动转报告 | `/select 2` 完成后不点确认 | 不自动启动 `/report` |
| 确认进入报告 | 选择一个“进入 /report”的标的并确认 | 创建报告任务 |
| 报告边界提示 | 打开由 select 触发的报告 | 报告说明“select 只表示值得进一步研究，不代表买入建议” |

## 二、价格提醒定时扫描

### 1. 创建价格提醒

| 用例 | 操作 | 期望 |
|---|---|---|
| 加密价格提醒 | 给 BTC 创建价格提醒 | 创建成功，归入 `CRYPTO:3m` 扫描桶 |
| A股价格提醒 | 给 600519 创建价格提醒 | 创建成功，归入 `CN_A:3m` 扫描桶 |
| 美股价格提醒 | 给 AAPL 创建价格提醒 | 创建提醒，但扫描桶暂时禁用，说明原因 |
| 港股价格提醒 | 给 00700.HK 创建价格提醒 | 第一版明确拒绝，不创建提醒 |
| 重复创建 | 同一个请求重复提交 | 不重复创建多条提醒 |

### 2. OpenClaw 定时任务

| 用例 | 操作 | 期望 |
|---|---|---|
| 创建第一个桶 | 创建第一个加密提醒 | 只创建一个 OpenClaw cron job |
| 同桶第二个提醒 | 再创建一个加密提醒 | 不重复创建 cron job |
| 定时任务参数 | 检查 cron job | 间隔 3 分钟，worker 是 price alert scan worker |
| 插件加载 | 启动运行环境后检查配置 | scheduled work 插件被加入 OpenClaw 插件路径 |
| 内部 token | 查看运行环境文件 | 存在内部唤醒 token，页面不显示 token |

### 3. 扫描和触发

| 用例 | 操作 | 期望 |
|---|---|---|
| 手动唤醒扫描 | 用内部入口唤醒 `price_alert_scan` | 返回扫描摘要 |
| 到价触发 | 模拟或等待真实报价达到阈值 | 提醒关闭，记录触发时间和 quote 证据 |
| 未到价 | 报价未达到阈值 | 提醒保持 active |
| 报价失败 | 数据源返回失败 | 提醒变 error，写清“检查失败”，不关闭提醒 |
| A股非交易时间 | 非交易时间扫 A股桶 | 不请求报价，记录跳过 |
| 加密任意时间 | 任意时间扫加密桶 | 不按交易时间跳过 |

## 三、Worker 追问

### 1. 普通聊天区

| 用例 | 操作 | 期望 |
|---|---|---|
| 打开首页 | 进入聊天页面 | 能看到 worker 选择器 |
| 默认 worker | 不手动选择直接提问 | 默认发给组合经理 |
| 选择 worker | 选择市场分析师后提问 | 回复来自市场分析师 |
| 非命令消息 | 输入普通问题 | 走 worker chat，不触发报告或选币 |
| 命令消息 | 输入 `/report BTC` 或 `/select 2` | 仍走命令流程，不走 worker chat |
| worker 不可用 | 菜单加载失败 | 页面提示刷新重试，不假装可用 |

### 2. 报告阅读区

| 用例 | 操作 | 期望 |
|---|---|---|
| 打开已完成报告 | 进入报告详情页 | 能选择 worker 提问 |
| 组合经理追问 | 问“最终风险是什么” | 基于报告和 PM 材料回答 |
| 市场分析师追问 | 问“走势怎么看” | 基于报告和市场材料回答 |
| 没有 worker 材料 | 选择缺少材料的 worker | 明确提示材料不可用，不编回答 |
| 问题含内部词 | 用户输入 hash、Mongo、OpenViking 等 | 发给 worker 前被清理或替换 |
| 回复格式 | 查看回复 | 支持 Markdown，不显示内部 session/provider/path |

### 3. OpenClaw 边界

| 用例 | 检查点 | 期望 |
|---|---|---|
| 会话创建 | 检查调用 | `sessions.create` 带目标 worker |
| 发送消息 | 检查调用 | 使用 `chat.send` |
| 禁用旧路 | 检查调用 | 不调用 `agent.runSingleWorker` |
| 不传控制字段 | 检查 payload | 不传 promptProfile、promptVariables、toolPolicy、visibleTools |
| 幂等冲突 | 同 requestId 改内容重发 | 返回冲突，不覆盖旧回复 |

## 四、报告流程受影响点

| 用例 | 操作 | 期望 |
|---|---|---|
| 前线并行默认值 | 新建报告任务 | 默认前线 worker 并行执行 |
| 显式串行 | 配置串行后新建报告任务 | 尊重串行配置 |
| select 报告提示 | 由选币确认生成报告 | 报告带 select 边界说明 |
| 普通报告 | 直接 `/report BTC` | 不写 select 边界说明 |
| 报告追问旧入口 | 使用旧报告问答接口 | 不返回 worker chat 格式 |

## 六、人工验收记录

每轮只记这些：

| 字段 | 内容 |
|---|---|
| 日期 | 具体日期和时间 |
| 提交 | 待测提交号 |
| 功能 | 加密选币 / 价格提醒 / worker 追问 |

## 七、停止条件

出现下面情况先停：

1. runtime 启动失败，或健康检查不可信。
2. OpenClaw cron 没有真正创建任务。
3. worker 追问绕过 OpenClaw，变成 Python 直接问 LLM。
4. 加密选币没有真实历史数据，却生成了候选结果。
5. 页面或报告暴露 token、路径、hash、Mongo、OpenViking、provider payload。
6. 报告把 select 候选当成买入建议。
