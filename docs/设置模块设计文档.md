## 1. 目标

首版设置模块只解决一件事：让用户完成生成报告所需的最小配置。

它不是高级诊断页，也不是 OpenClaw 主界面的复制品。

## 2. 启动检查

项目启动后自动检查两类状态：

- 报告模型
- 微信通知

报告模型是硬前置。没有配置、没有测试通过、或测试失败时，直接进入模型配置表单，不能生成报告。

微信通知是启动引导，不是硬阻断。未配置时直接显示二维码和引导文案，用户可以跳过并进入浏览器工作台。

缺报告模型时，界面直接进入配置表单，不出现“配置模型”二次入口。

## 3. OpenClaw 引导项

OpenClaw 负责运行底座能力：

- 模型配置和模型测试
- 设备授权和 scope 处理
- 微信插件、二维码、登录状态和通道能力

普通 UI 不显示：

- OpenClaw 原始配置
- scope 细节
- gateway 地址
- Channel ID
- 插件包名
- 配置路径

OpenClaw 主界面入口放在聊天界面工具区，不放在设置页。

## 4. 模型设置

报告模型字段：

- 服务商
- 模型
- API key
- 接口地址

报告模型状态：

- 未配置
- 已保存未验证
- 测试失败
- 可用

规则：

- 测试通过前不能生成报告。
- 测试失败时显示可操作错误。
- 用户配置优先。
- 不允许测试失败后静默切换到默认模型。
- 保存配置不等于测试通过。

Embedding 是可选项，用于语义检索。未配置或不可用时不阻断报告生成。

## 5. 微信通知

启动引导和设置页都直接展示二维码，不先放“扫码登录”二次按钮。

固定文案：

```text
请先在微信端启用插件：
我 → 设置 → 插件 → 微信 ClawBot

按微信端提示安装或启用后，返回本页扫描二维码完成连接。
```

操作：

- 刷新二维码
- 稍后设置
- 重新连接
- 解除连接

规则：

- 二维码必须来自真实 OpenClaw 通道。
- 不伪造登录成功。
- 未登录不阻断浏览器工作台。
- 不在 UI 写微信端报告指令用法。
- 普通 UI 不暴露内部 Channel ID 或插件包名。

## 6. 增强数据源

设置页显示固定内置、需要用户填写密钥或凭证的全球主流外部增强源目录，不开放任意 HTTP / JSON。系统默认免费源、免密源和内部统一接入层不在普通设置页显示。目录按两级组织：

1. 市场 tab：A股、港股、美股、跨市场/宏观、加密货币。
2. 功能卡片：行情、基本面、新闻公告、社交舆情、宏观经济、链上与基本面等。

每个功能卡片内用下拉列表选择该功能可用的数据源。同一个数据源只保存一份配置；如果它同时出现在多个市场或功能里，一处填写后，其他位置显示同一份已设置、启用、最近测试和掩码密钥状态。

普通设置页固定目录包括但不限于：

- A股：Tushare、Wind、Choice、iFinD、CSMAR、RESSET、JoinQuant、RiceQuant。
- 港股/美股/跨市场行情与基本面：LongPort、IEX Cloud、Twelve Data、Marketstack、EODHD、Intrinio、Alpha Vantage、FMP、Polygon、Finnhub、Tiingo、Nasdaq Data Link、Bloomberg、LSEG Refinitiv、FactSet、Morningstar、S&P Capital IQ、TradingView、Barchart、Finazon。
- 新闻、社交和宏观：Benzinga、NewsAPI、Reuters、Dow Jones、X.com、FRED、BEA、EIA。
- 加密货币：CoinGecko Pro、CoinMarketCap、Coinglass、CryptoCompare、Messari、Glassnode、Santiment、Coin Metrics、Dune、Nansen、Token Terminal、The Graph、Kaiko、Amberdata、LunarCrush。

AKShare、东方财富、Yahoo Finance、SEC EDGAR、CoinGecko 免费/公共接口、Binance、OKX、CCXT 等默认源、免密源或内部接入层不作为普通设置页可编辑项展示。已删除数据网关 本体已删除，不作为当前设置页数据源或运行时入口。

字段：

- 固定内置源名称（只读显示）
- API key
- 接口地址
- 启用开关
- 最近测试结果

规则：

- 启用前必须测试通过。
- 启用后只在系统批准范围内优先尝试。
- 运行时失败不阻断报告。
- 默认源可覆盖时继续生成报告。
- 失败 attempt 必须记录。

不支持：

- 任意 HTTP 数据源
- 自定义 JSON 映射
- 用户调整 provider 优先级
- 用户选择数据源适用范围

## 7. 任务卡片

用户输入标的后，系统自动识别并生成确认卡。

卡片字段：

```text
标的：600519.SH
名称：贵州茅台
市场：[A股 v]
```

用户可以：

- 确认生成报告
- 修改标的
- 切换市场

市场默认使用识别结果。用户切换市场后，系统重新校验标的是否匹配。不匹配时提示用户修改标的或选择匹配项。

任务卡片不显示：

- profile
- 默认币种
- 报告方案
- 计价单位
- worker / debate / risk 细节

## 8. UI 文案边界

普通 UI 不显示：

- profile
- 默认币种
- worker id
- provider attempt
- runtime 细节
- evidence 链路细节
- OpenClaw 内部 Channel ID
- OpenClaw 插件包名

任务卡片允许显示“市场”，因为这是用户确认和纠错所需字段。

普通 UI 不写未经确认的说明或猜测性承诺。

## 9. 阻断规则

阻断报告生成：

- 报告模型未配置
- 报告模型未测试通过
- 报告模型测试失败

不阻断报告生成：

- Embedding 未配置
- 微信未登录
- 增强数据源运行失败但默认源可覆盖

## 10. 高级诊断 Follow-Up

以下只进入高级诊断 follow-up，不进首版普通设置页，也不进首次配置主路径，除非它直接阻断报告生成：

- provider 健康
- runtime 服务状态
- 最近 live run 缺口
- 证据链失败原因

高级诊断只显示面向诊断的摘要，不把 provider attempt、runtime 内部细节或 evidence 链路细节暴露到普通 UI。

## 11. 视觉与 CSS 设计

适用目标：

- `web/research-ui/src/styles.css`
- 设置启动引导
- 设置页
- 报告任务确认卡片

实现时复用现有 `ct-*` 命名体系，不做无关全站重构。

视觉目标：

- 像专业投研工具
- 浅色背景
- 白色工作面板
- 细边框
- 小状态标签
- 低饱和按钮
- 无大渐变
- 无 hero
- 无装饰图形
- 无嵌套卡片
- 不像营销页
- 不像复杂后台

CSS 文件级覆盖范围：

- tokens
- page shell
- 启动引导布局
- 表单控件
- 按钮
- 状态标签
- 微信二维码区
- 设置页三块结构
- 模型区块布局
- 增强数据源列表
- 任务确认卡片
- 错误态和空态
- 响应式
- motion

设置页使用三块主面板，不做全页 tab。增强数据源面板内部允许市场 tab：

1. 模型
2. 增强数据源
3. 微信通知

报告模型在上，Embedding 在下。Embedding 使用弱边框分隔，不做嵌套卡片。

增强源使用“市场 tab + 功能卡片 + 数据源下拉”。不把每个数据源做成一张大卡片堆叠。

任务卡片要短，不能像表单页。

错误提示只说用户能做什么。

响应式规则以桌面优先，移动端只保证能用。

motion 只允许微动效，不做页面级动画。

## 12. 实现边界

必须保持最小、手术式实现：

- 不添加设计文档未批准的功能、字段、入口、状态、配置项或诊断项。
- 不做顺手重构。
- 不做全局优化。
- 不通过 mock、fake、stub、fallback 假装实现。
- 不隐藏真实错误。
- 不把保存配置等同于测试通过。
- 不把模型测试失败静默切换到默认模型。
- 不把微信设成浏览器工作台硬阻断。
- 不让用户选择 profile、默认市场、默认币种、worker / debate / risk 轮数。
- 不允许任意 HTTP / JSON 数据源、provider 优先级调整或数据源适用范围选择。

如果实现需要改变 OpenClaw 非通用 runtime seam、PM 权限、direct LLM 路径、fallback、硬门禁、provider payload 要求、HK/CRYPTO 策略或 worker 调度边界，必须停下回到人类确认。

## 13. 验证纪律

每项实现必须能被真实运行、真实 UI、真实状态、真实错误、真实日志或真实测试验证。

对于需要 live/fresh/provider 运行的验证，必须遵守固定 runtime preflight，并通过：

```text
scripts/start-control-runtime.sh -- <command>
```

不能用静态 render、日志拼接、伪造状态或 capture-only 结果替代真实验证。
