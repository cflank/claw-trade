# 生产及升级操作手册

## 0. 变量

```bash
TARGET_IP="192.168.1.21"
TARGET_USER="frank"
DELIVERY_BASE="https://download.cflank-trade.top/delivery"
STABLE_BASE="https://download.cflank-trade.top/stable"
MIN_CURRENT_VERSION="1.0.0"
```

远程升级只认 `manifest.version` 是否高于目标机当前版本。同版本重打包、新时间戳、新 sha256 都不会触发更新；发升级前先把 `pyproject.toml` 里的 `project.version` 升高。

## 3. 打生产包

```bash
cd /home/frank/src/claw-trade

python3.12 - <<'PY'
import tomllib
print(tomllib.load(open("pyproject.toml", "rb"))["project"]["version"])
PY

scripts/production/build_production_package.sh
scripts/production/build_virbox_protected_delivery_package.sh

PKG="$(find /mnt/d/claw-trade-virbox/delivery-output -mindepth 2 -maxdepth 2 -type f -name 'claw-trade-production-*.tar.gz' -printf '%T@ %p\n' | sort -nr | head -n 1 | cut -d' ' -f2-)"
test -n "$PKG"
OUT_DIR="$(dirname "$PKG")"
REL="$(basename "$PKG" .tar.gz)"

cd "$OUT_DIR"
sha256sum -c "${REL}.tar.gz.sha256"
```

如果终端先打印 `WSL ... UtilAcceptVsock ... accept4 failed 110`，那是 WSL 噪声，不是打包失败；看后面的 `sha256sum` 或脚本错误。

产物：

```text
$OUT_DIR/$REL.tar.gz
$OUT_DIR/$REL.tar.gz.sha256
```

## 6. 发远程升级

先跑第 3 节。

```bash
cd "$OUT_DIR"

REL="$(basename "$(ls -t claw-trade-production-*.tar.gz | head -n 1)" .tar.gz)"
VERSION="$(python3.12 - <<'PY'
import tomllib
print(tomllib.load(open("/home/frank/src/claw-trade/pyproject.toml", "rb"))["project"]["version"])
PY
)"
SHA256="$(sha256sum "${REL}.tar.gz" | awk '{print $1}')"

openssl pkeyutl -sign \
  -inkey /home/frank/src/claw-trade/update-signing-private.pem \
  -rawin \
  -in "${REL}.tar.gz" \
  -out "${REL}.tar.gz.sig"

cat > manifest.json <<EOF
{
  "product": "claw-trade",
  "channel": "stable",
  "version": "${VERSION}",
  "arch": "linux-x86_64",
  "archive": "${REL}.tar.gz",
  "sha256": "${SHA256}",
  "created_at": "$(date -u +%Y-%m-%dT%H:%M:%SZ)",
  "min_current_version": "${MIN_CURRENT_VERSION}",
  "notes": "production update"
}
EOF

openssl pkeyutl -sign \
  -inkey /home/frank/src/claw-trade/update-signing-private.pem \
  -rawin \
  -in manifest.json \
  -out manifest.json.sig
```

产物：

```text
$OUT_DIR/$REL.tar.gz
$OUT_DIR/$REL.tar.gz.sig
$OUT_DIR/manifest.json
$OUT_DIR/manifest.json.sig
```

## 7. 上传远程升级文件

R2 没有对象链接或 symlink。生产大包已经在 `delivery/` 上传后，升级大包用 R2 内部复制到 `stable/`，不要重复上传大包。

Win11 PowerShell：

```powershell
cd D:\claw-trade-virbox\r2-delivery-upload
$Endpoint="https://ea28643cc0d5f658900f58342c00d045.r2.cloudflarestorage.com"
$Profile="cloudflare-r2"
$Bucket="claw-trade-delivery"
$Pkg=Get-ChildItem "D:\claw-trade-virbox\delivery-output" -Recurse -Filter "claw-trade-production-*.tar.gz" | Sort-Object LastWriteTime -Descending | Select-Object -First 1
$D=$Pkg.DirectoryName
$REL=$Pkg.Name -replace '\.tar\.gz$',''
aws s3api copy-object --bucket $Bucket --copy-source "$Bucket/delivery/$REL.tar.gz" --key "stable/$REL.tar.gz" --endpoint-url $Endpoint --profile $Profile
.\upload-delivery.cmd "$D\$REL.tar.gz.sig" -Key "stable/$REL.tar.gz.sig"
.\upload-delivery.cmd "$D\manifest.json" -Key "stable/manifest.json"
.\upload-delivery.cmd "$D\manifest.json.sig" -Key "stable/manifest.json.sig"
```

检查：

```powershell
curl.exe -I "https://download.cflank-trade.top/stable/manifest.json"
curl.exe -I "https://download.cflank-trade.top/stable/manifest.json.sig"
curl.exe -I "https://download.cflank-trade.top/stable/$REL.tar.gz"
curl.exe -I "https://download.cflank-trade.top/stable/$REL.tar.gz.sig"
```

## 9. 延长授权

先在 Virbox 开发者平台改到期日。

目标机执行：

```bash
KEY="$(tr -d '[:space:]' < "$HOME/.claw-trade/license.key")"
/opt/senseshield/ssclt --online_refresh_license --license_key "$KEY"
```

验证：

```bash
/opt/senseshield/ssclt -l all
curl -fsS http://127.0.0.1:5175/api/ui/get-license-status
```

通过标志：

```text
LicenseKeyStatus:Normal
"status":"activated"
expiresAt 变成新日期
```

许可 ID 变了就停，先确认包里的 `VIRBOX_LICENSE_ID`。

## 10. 什么时候重做 Virbox 加密

不用重做：

```text
只改代码、prompt、前端、配置。
只改同一个许可 ID 的授权日期。
```

必须重做：

```text
许可 ID 变了。
DS 密码或 API 密码变了。
Python/Node runtime 换了。
保护策略变了。
```
