## 3. 生成最终交付包

```bash
cd /home/frank/src/claw-trade

scripts/production/build_production_package.sh
scripts/production/build_virbox_protected_delivery_package.sh

OUT_DIR="$(find /mnt/d/claw-trade-virbox/delivery-output -mindepth 1 -maxdepth 1 -type d | sort | tail -n 1)"
PKG="$(ls -t "$OUT_DIR"/claw-trade-production-*.tar.gz | head -n 1)"
REL="$(basename "$PKG" .tar.gz)"

cd "$OUT_DIR"
sha256sum -c "${REL}.tar.gz.sha256"
```

最终给客户安装用：

```text
$OUT_DIR/$REL.tar.gz
$OUT_DIR/$REL.tar.gz.sha256
```

## 5. 目标机首次安装

登录目标机：

```bash
ssh "$TARGET_USER@$TARGET_IP"
```

首次安装 Virbox 保护包前，目标机先执行一次；第一条有输出就跳过后面几条：

```bash
grep 'split_lock_detect=off' /proc/cmdline

sudo cp -a /etc/default/grub "/etc/default/grub.bak-claw-trade-$(date -u +%Y%m%dT%H%M%SZ)"
grep -q 'split_lock_detect=off' /etc/default/grub || sudo sed -i 's/^GRUB_CMDLINE_LINUX_DEFAULT="\([^"]*\)"/GRUB_CMDLINE_LINUX_DEFAULT="\1 split_lock_detect=off"/' /etc/default/grub
sudo update-grub
sudo reboot
```

重启后重新登录，确认：

```bash
grep 'split_lock_detect=off' /proc/cmdline
```

安装：

```bash
REL="claw-trade-production-1.0.0-20260706T053438Z"
BASE="https://download.cflank-trade.top/delivery"

cd /tmp
umask 077
printf '%s\n' '这里粘贴 Virbox 授权码' > /tmp/license.key
curl -fL -o install_from_r2_ubuntu.sh "${BASE}/install_from_r2_ubuntu.sh"
bash /tmp/install_from_r2_ubuntu.sh "$REL" --license-key-file /tmp/license.key
```

脚本会自动下载并安装这些文件：

```text
delivery/$REL.tar.gz
delivery/$REL.tar.gz.sha256
delivery/senseshield-lcc-2.7.5.69040-amd64.deb
delivery/install_factory_test_ubuntu.sh
delivery/validate_production_archive.py
delivery/update-signing-public.pem
```

手动重测前，把目标机恢复成新机状态：

```bash
ssh "$TARGET_USER@$TARGET_IP"

KEY_FILE="/tmp/license.key"
if [[ -x /opt/senseshield/ssclt && -f "$KEY_FILE" ]]; then
  KEY="$(tr -d '[:space:]' < "$KEY_FILE")"
  /opt/senseshield/ssclt --online_unbind_license_key --license_key "$KEY" || true
fi

sudo systemctl disable --now claw-trade-auto-update.timer 2>/dev/null || true
sudo systemctl disable --now claw-trade.service claw-trade-ui.service claw-trade-auto-update.service 2>/dev/null || true
sudo pkill -f 'claw-trade-control-runtime' 2>/dev/null || true
sudo pkill -f 'claw_trade.runtime.openviking_report_server' 2>/dev/null || true
sudo pkill -f 'claw_trade.web.app' 2>/dev/null || true
sudo pkill -f 'openclaw$' 2>/dev/null || true

sudo rm -rf /opt/claw-trade /etc/claw-trade /usr/local/lib/claw-trade
sudo rm -f /etc/systemd/system/claw-trade*.service /etc/systemd/system/claw-trade*.timer /etc/sudoers.d/claw-trade-update
sudo systemctl daemon-reload || true

sudo apt-get purge -y senseshield 2>/dev/null || true
sudo rm -rf /opt/senseshield /var/log/senseshield /etc/senseshield

if id -u clawtrade >/dev/null 2>&1; then sudo userdel -r clawtrade 2>/dev/null || sudo userdel clawtrade; fi
if id -u clawkiosk >/dev/null 2>&1; then sudo userdel -r clawkiosk 2>/dev/null || sudo userdel clawkiosk; fi
if getent group clawtrade >/dev/null; then sudo groupdel clawtrade 2>/dev/null || true; fi
if getent group clawkiosk >/dev/null; then sudo groupdel clawkiosk 2>/dev/null || true; fi

sudo rm -f /tmp/claw-trade-production-*.tar.gz /tmp/claw-trade-production-*.tar.gz.sha256
sudo rm -f /tmp/install_factory_test_ubuntu.sh /tmp/install_from_r2_ubuntu.sh /tmp/validate_production_archive.py /tmp/update-signing-public.pem /tmp/senseshield-lcc-*.deb
```

```bash

! getent passwd clawtrade

```

## 6. 发布远程升级

先改版本号，再重新跑第 3 节生成新包。

```bash
cd "$OUT_DIR"

VERSION="1.0.1"
MIN_CURRENT_VERSION="1.0.0"
SHA256="$(sha256sum "${REL}.tar.gz" | awk '{print $1}')"

openssl pkeyutl -sign \
  -inkey /home/frank/src/claw-trade/update-signing-private.pem \
  -rawin \
  -in "${REL}.tar.gz" \
  -out "${REL}.tar.gz.sig"

cat > manifest.json <<EOF
{
  "product": "claw-trade",
  "channel": "stable",
  "version": "${VERSION}",
  "arch": "linux-x86_64",
  "archive": "${REL}.tar.gz",
  "sha256": "${SHA256}",
  "created_at": "$(date -u +%Y-%m-%dT%H:%M:%SZ)",
  "min_current_version": "${MIN_CURRENT_VERSION}",
  "notes": "production update"
}
EOF

openssl pkeyutl -sign \
  -inkey /home/frank/src/claw-trade/update-signing-private.pem \
  -rawin \
  -in manifest.json \
  -out manifest.json.sig
```

上传到 R2，顺序不能错：

```text
stable/$REL.tar.gz
stable/$REL.tar.gz.sig
stable/manifest.json
stable/manifest.json.sig
```

对应本地文件：

```text
$OUT_DIR/$REL.tar.gz
$OUT_DIR/$REL.tar.gz.sig
$OUT_DIR/manifest.json
$OUT_DIR/manifest.json.sig
```

检查：

```text
https://download.cflank-trade.top/stable/manifest.json
https://download.cflank-trade.top/stable/manifest.json.sig
https://download.cflank-trade.top/stable/$REL.tar.gz
https://download.cflank-trade.top/stable/$REL.tar.gz.sig
```

## 8. 什么时候重做 Virbox 加密

不用重做：

```text
只改代码、prompt、前端、配置。
只改同一个许可 ID 的授权日期。
```

必须重做：

```text
许可 ID 变了。
DS 密码或 API 密码变了。
Python/Node runtime 换了。
保护策略变了。
```

## 9. 安装失败先看这几条

缺 Virbox 状态 SDK：

```bash
techlab/virbox_probe/build_virbox_status_sdk.sh
scripts/production/build_production_package.sh
scripts/production/build_virbox_protected_delivery_package.sh
```

安装日志必须看到：

```text
[INFO] installing Virbox status SDK
```

如果 Virbox 后台显示授权到期日正确，但页面仍显示未授权，先确认目标机接口：

```bash
curl -fsS http://127.0.0.1:5175/api/ui/get-license-status
```

`status=activated` 才算通过。Virbox 原始状态 `1` 表示“即将过期”，不是不可用。

Virbox 在线绑定反复报 `操作超时 (0x00000009)`：

```bash
grep -RIn 'ChinaVBPGlobalCDN\|MSG_TIMEOUT\|operationTimeout' \
  /opt/senseshield/etc/common/ss_cloud.xml \
  /opt/senseshield/etc/ss_service/ss_config.xml \
  /opt/senseshield/ss_config.xml \
  /opt/senseshield/etc/license_control_center/virboxlcc_config.json
```

必须看到：

```text
ChinaVBPGlobalCDN" Default=1
MSG_TIMEOUT>60000
operationTimeout" : 60000
```
