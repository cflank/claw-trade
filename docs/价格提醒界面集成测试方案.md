# 价格提醒界面集成测试方案

## 测试目标

验证用户从界面创建价格提醒后，系统能按市场扫描桶注册一个 OpenClaw 定时任务，
定时任务到点唤醒 `price_alert_scan_worker`，再由 claw-trade 完成报价读取、
触发判断、通知记录和用户可见状态更新。

## 测试范围

- 价格提醒创建、暂停、恢复、删除、立即检查。
- `CRYPTO`、`CN_A`、`US`、`HK` 市场边界。
- 同市场同频率扫描桶复用，一个桶只创建一个定时任务。
- OpenClaw 定时任务真实唤醒 worker，并调用内部唤醒路由。
- 报价可用、报价不可用、通知渠道不可用三类结果。
- 普通聊天和 `/report` 工作流不被价格提醒误触发。

不测：技术指标提醒、AI 解释、自动报告生成、港股提醒成功路径。

## 环境准备

1. 使用固定运行入口启动：

```bash
CLAW_TRADE_ENV_PATH=/home/frank/src/claw-trade/.env.local \
scripts/start-research-ui.sh
```

2. 启动后确认：

| 检查项 | 预期结果 |
| --- | --- |
| OpenViking `1933` 健康检查 | 通过 |
| OpenClaw gateway `18789` 健康检查 | 通过 |
| 界面后端 `8787` | 通过 |
| 大模型供应商 | `deepseek` |
| 模型 | `deepseek/deepseek-chat` |

3. 清理或备份 `runs/.ui-scheduled-work.json`，避免旧提醒影响结果。

## 测试用例

| 编号 | 场景 | 步骤 | 预期结果 |
| --- | --- | --- | --- |
| PA-UI-001 | 创建 CRYPTO 价格阈值提醒 | 在界面创建 BTC 高于指定价格提醒 | 返回用户可见提醒对象；状态为 `active`；不暴露定时任务编号、证据引用、去重键 |
| PA-UI-002 | 同桶复用定时任务 | 连续创建两个 CRYPTO/BTC 提醒 | 两条提醒都在 `CRYPTO:3m`；OpenClaw 只有一个 `price-alert-scan:CRYPTO:3m` 任务 |
| PA-UI-003 | 并发创建同桶提醒 | 同时提交两个 CRYPTO 提醒创建请求 | 只创建一个扫描桶和一个定时任务；提醒编号不重复 |
| PA-UI-004 | A 股提醒 | 创建 `600519.SH` 或 `SH600519` 提醒 | 代码规范化；扫描桶为 `CN_A:3m` |
| PA-UI-005 | 美股提醒 | 创建 AAPL 提醒 | 创建提醒和 `US:3m` 扫描桶；扫描阶段标记跳过，直到美股报价和日历证据补齐 |
| PA-UI-006 | 港股拒绝 | 创建 `00700.HK` 提醒 | 返回 `INVALID_INPUT`；不创建提醒、不创建定时任务 |
| PA-UI-007 | 立即检查报价成功 | 使用可返回 `current_price`、`quote_timestamp`、`evidence_ref` 的报价源运行检查 | 条件命中则提醒关闭并记录通知结果；条件未命中则保持 `active` |
| PA-UI-008 | 立即检查报价失败 | 报价源缺失或 payload 无证据 | 提醒进入 `error`；展示“价格提醒检查失败，请稍后重试。”；不伪造价格 |
| PA-UI-009 | 定时任务唤醒扫描 | 强制运行 OpenClaw 定时任务 | run history 为 `ok`；worker 为 `price_alert_scan_worker`；只调用内部唤醒工具 |
| PA-UI-010 | 同代码合并报价 | 同桶内两个 BTC 提醒触发扫描 | 扫描摘要的 `grouped_quote_count=1` |
| PA-UI-011 | 通知渠道可用 | 条件命中且 channel 可用 | 记录真实 channel 发送结果；提醒关闭 |
| PA-UI-012 | 通知渠道不可用 | 条件命中但 channel 不可用 | 写入站内通知；不得声称微信发送成功；提醒仍关闭 |
| PA-UI-013 | 通知去重 | 对同一提醒、条件版本、报价时间重复扫描 | 只通知一次；去重键持久化 |
| PA-UI-014 | 暂停提醒 | 暂停后触发扫描或立即检查 | 不请求报价；返回未触发；状态保持 `paused` |
| PA-UI-015 | 恢复提醒 | 恢复暂停提醒后触发扫描 | 状态变 `active`；后续扫描可检查 |
| PA-UI-016 | 删除提醒 | 删除后触发扫描 | 提醒不进入 active 扫描列表 |
| PA-UI-017 | 不生成报告 | 价格提醒命中 | 不创建报告确认卡、不进入 `/report` 队列 |
| PA-UI-018 | 普通聊天隔离 | 发送普通聊天或非价格提醒消息 | 不创建价格提醒、不创建定时任务 |

## 证据要求

每次界面集成测试至少保留：

- 界面操作记录或接口请求/响应。
- `runs/.ui-scheduled-work.json` 中的提醒、扫描桶、扫描摘要。
- OpenClaw `cron/jobs.json`、`cron/jobs-state.json`、对应运行历史。
- worker 会话或轨迹，证明供应商为 DeepSeek，工具只暴露内部唤醒工具。
- 报价证据引用；若不可用，记录失败关闭原因。

## 通过标准

- 用户可见对象不暴露内部字段。
- 一个扫描桶只对应一个 OpenClaw 定时任务。
- 定时任务能真实唤醒 `price_alert_scan_worker`。
- 价格判断由 claw-trade 确定性执行，LLM 不判断价格。
- 无报价证据时失败关闭，不伪造触发或通知。
- 价格提醒不触发报告工作流。
