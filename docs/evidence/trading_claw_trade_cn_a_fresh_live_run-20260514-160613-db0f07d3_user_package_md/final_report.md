## 三、基本面分析

### 3.1 收入与盈利质量：高利润率下的增长换挡

截至2026年3月31日（最新报告期）：

| 指标 | 数值 | 经营含义 |
| :-- | :-- | :------ |
| 营业收入 | 539.09亿元 | 同比+6.34%，增速降至个位数，创近年新低 |
| 净利润 | 281.54亿元 | 与营收增长同步放缓 |
| 每股收益（EPS） | 21.76元/股 | 估值计算基础 |
| 毛利率 | 89.76% | A股顶尖水平，品牌溢价稳固，成本控制优异 |
| 净利率 | 52.22% | 每100元收入赚取52元净利润，盈利能力极高 |
| ROE | 10.57%（单季） | 年化后约40%以上，典型高资本回报率企业 |

**分析链：**
- **毛利率89.76%**是当前最坚固的基本面支撑，表明产品定价权和品牌护城河未受冲击。只要毛利率不出现系统性下滑，茅台的基本盘依然稳固。
- **净利率52.22%**意味着盈利转化效率极高，公司无需通过大量资本开支或财务杠杆来维持盈利。
- **营收增速6.34%**是核心矛盾。从历史20-30%的增速下降至个位数，意味着市场对茅台的估值逻辑必须重构——从“高成长稀缺资产”向“稳健消费品”切换。

**投资含义**：高利润率提供安全边际，但增速放缓正在侵蚀估值溢价。如果6.34%成为新常态，茅台的估值中枢应从30-40倍PE向全球消费品龙头的18-22倍PE靠拢。

**削弱条件**：若后续季度营收增速跌破5%，或毛利率出现下滑（>1个百分点），则基本面恶化信号将进一步强化。

### 3.2 现金流质量：利润“含金量”尚可，但结构隐忧

- **经营现金流**：269.10亿元（2026年Q1）
- 经营现金流绝对值庞大，与净利润匹配度较高，表明盈利不依赖应收账款或非现金项目调节

**关键风险**：经营现金流中包含合同负债变动的“拖累效应”。2026年Q1合同负债大幅下降约50-60亿元，意味着实际经营现金流的“质量”出现了结构性下降。若剔除这一因素，核心经营现金流可能低于表面数字所反映的健康程度。

### 3.3 资产负债结构：极低杠杆，穿越周期的底气

- **资产负债率**：12.12%——A股最低水平之一，财务杠杆风险几乎为零
- 低负债率 + 高毛利率 + 高净利率，使茅台具备极强的抗周期能力

**投资含义**：即使在最悲观的情景下（营收增速降至0%，批价持续下行），茅台也远不会出现偿债风险或流动性危机。这为“等待基本面见底”提供了时间窗口。

### 4.2 事件影响机制

**合同负债暴跌65%的传导路径：**
- 旧逻辑：合同负债是“蓄水池” → 代表未来收入确定性 → 支撑高估值
- 新现实：渠道结构变化（直销比例提升） → 经销商预付减少 → 合同负债自然下降
- **关键风险**：合同负债下降与**飞天茅台批发价持续下跌**同步发生。如果终端需求强健，即使渠道变革，经销商也应愿意预付。经销商“用脚投票”不再预付，说明他们对未来销售没信心——这是终端需求在降温的强烈信号。

**组合经理的判断**：这不是简单的“阵痛”，而是“蓄水池正在被抽干”的危险信号。
