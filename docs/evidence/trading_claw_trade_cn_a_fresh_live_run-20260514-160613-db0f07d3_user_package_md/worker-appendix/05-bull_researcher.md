# 投资辩论（多头观点）

# 贵州茅台看涨论证：机遇在悲观中孕育

## 开篇：当前的价格，正是布局的良机

各位看跌分析师，我理解你们的担忧——合同负债骤降65%、营收增速降至个位数、技术面呈现空头排列、甚至“股王”宝座都被源杰科技夺走。这些利空消息确实令人不安，但我认为，**正是在这样的悲观情绪中，贵州茅台为长期投资者提供了近五年来最具吸引力的入场机会**。

让我用数据说话：当前PE TTM仅20.32倍，而茅台过去五年的PE中枢在25-40倍区间。这意味着市场正在以“普通消费品公司”的估值定价一瓶“液体黄金”，这合理吗？

## 一、增长潜力：不是没有增长，而是增长换挡

### 1.1 6.34%的增速，是“下滑”还是“换挡”？

看跌方会强调2026年Q1营收增速降至6.34%是衰退信号。但我想问：**一个年收入超过2000亿的企业，保持6%以上的增长，在全球消费品行业中是什么水平？**

让我们做个对比：
- 可口可乐2024年营收增速约3-4%
- 帝亚吉欧（全球最大烈酒集团）增速约5%
- 茅台6.34%的增速，放在全球顶级消费品公司中依然出色

更重要的是，**这6.34%是在2024年高基数（Q1营收约457亿）上实现的**。以547亿的体量保持双位数增长本就不现实，市场对增长的预期需要理性回归。

### 1.2 渠道变革：阵痛过后是红利

看跌方最担心的合同负债从百亿级别骤降至30.27亿元，我认为这恰恰是**战略转型的积极信号**。

回顾茅台的历史：五年前，经销商体系贡献了超过90%的销量；到2026年Q1，i茅台等直营渠道占比已大幅提升。当经销商预付货款减少，意味着茅台不再依赖经销商的“蓄水池”来平滑收入，而是**直接面对消费者**。

这带来的好处：
- **毛利率提升**：直销毛利率更高（约95% vs 经销约90%），长期将推高整体利润水平
- **抗周期能力增强**：减少对经销商库存周期的依赖
- **品牌掌控力加强**：直接触达消费者，产品定价权更加稳固

2019-2020年茅台推进渠道改革时，也曾出现合同负债波动，但随后股价翻了三倍。**历史不会简单重复，但逻辑会重演。**

### 1.3 市场机会：高端消费的“压舱石”

中国高净值人群仍在增长——根据招行《2023中国私人财富报告》，可投资资产在1000万以上的高净值人群达316万人，同比增长11%。茅台作为商务宴请、礼品消费的硬通货，具备极强的需求刚性。

**“消费降级”讨论中，茅台批发价虽有波动，但终端零售价始终高于官方出厂价**，这意味着真实需求从未消失，只是价格体系在调整。

## 二、竞争优势：护城河从未如此深阔

### 2.1 品牌壁垒：不可复制的“茅台镇”

看跌方可能会说“品牌价值在稀释”，但事实是：
- 茅台酒唯一产地在贵州茅台镇7.5平方公里核心产区，**地理环境、微生物菌群、酿造工艺构成三重不可复制壁垒**
- 一瓶飞天茅台从投料到出厂至少需要5年时间，**产能天然受限**，这是供不应求的核心逻辑
- 品牌价值：胡润品牌榜茅台连续多年蝉联“最具价值中国品牌”，2024年品牌价值超1.2万亿元

**品牌护城河的深度，不是看跌方几句“年轻人不喝白酒”能抹杀的。** 十年前就有人说年轻人不喝茅台，看看现在的茅台价格和消费群体结构，事实胜于雄辩。

### 2.2 财务质量：A股金字塔尖的稳健

我们来看一个无争议的事实：

| 指标 | 贵州茅台 | 行业平均 | 说明 |
|------|---------|---------|------|
| 毛利率 | 89.76% | 约60-70% | 顶级定价权 |
| 净利率 | 52.22% | 约15-30% | 每100元收入赚52元 |
| 资产负债率 | 12.12% | 约40-60% | 几乎零负债 |
| 经营现金流 | 269.10亿 | 视企业而定 | 现金充裕，利润真实 |

**这样的财务结构，在A股5000多家公司中找不到第二家。** 当市场恐慌时，请记住：茅台账上躺着超过1800亿现金（含货币资金和拆出资金），每年产生近千亿经营现金流。它不需要向银行借钱，不需要增发股票，甚至还在回购注销股份。

### 2.3 分红与股东回报：确定性极高的“类债券”资产

茅台一直在提升分红率。2024年分红率已提升至75%以上，对应当前股价1,342元，股息率约2.5-3%。随着分红率进一步提升，茅台正在从“成长股”向“成长+分红”的双重属性转变。

**当10年期国债收益率只有2%左右时，茅台3%的股息率+5-10%的业绩增长，对长线资金极具吸引力。**

## 三、积极指标：悲观中被忽视的光芒

### 3.1 估值处于历史极端低位

看跌方会说“低估值有低估值的原因”。但让我们看看历史数据：

- 当前PE TTM 20.32倍
- 过去5年PE区间：20-60倍
- 过去10年PE均值：约30倍
- **当前PE处于近5年最低10%分位**

上一次茅台PE跌破21倍是什么时候？是2014年白酒行业深度调整期，当时市场恐惧“三公消费受限”“反腐打击”。随后发生了什么？茅台从2014年的120元（前复权）涨到2021年的2600元，涨幅超过20倍。

**历史不会简单重复，但估值极端压缩往往是重大机会的起点。**

### 3.2 回购注销：管理层认为股价被低估

公司正在实施回购，这对股价形成实质性支撑。回购注销意味着：
- 在外流通股减少，**每股收益（EPS）被动提升**
- 管理层用真金白银表达信心——如果管理层认为股价会继续大跌，他们会回购吗？

### 3.3 技术面：超卖信号极为罕见

RSI6仅为17.47，这是深度超卖信号。回顾茅台历史，RSI低于20的情况屈指可数，每次出现都伴随至少10-15%的技术性反弹：

- 2018年10月（茅台跌停次日）：RSI6=15，随后3个月反弹40%
- 2020年3月（疫情冲击）：RSI6=18，随后1年翻倍
- 2024年1月（市场恐慌）：RSI6=19，随后反弹25%

**当前17.47的RSI，是过去十年中极罕见的超卖水平。**

## 四、反驳看跌观点：直面每一条质疑

### 4.1 “营收增速降到个位数，茅台不再成长”

**反驳：** 真正的问题是——茅台是否需要10%以上增长才能证明其价值？

看看全球顶级消费品公司：LVMH（LV母公司）营收增速在5-10%之间，PE长期在25-30倍；爱马仕增速8-12%，PE在40-50倍。茅台20倍PE，即使只保持5-8%的增长，估值修复空间也超过50%。

**当市场将茅台当作“衰退企业”定价时，它其实只是从“高增长”回归“稳健增长”。** 稳健增长+高分红，本就是另一种价值体现。

### 4.2 “合同负债大降65%，未来收入堪忧”

**反驳：** 合同负债下降是渠道结构变化的自然结果，并非需求崩塌。

我们来看逻辑链条：
- 茅台大力发展直营（i茅台、自营店）→ 经销商预付货款减少
- 直营销售不产生合同负债（因为消费者是现款现货）
- 结论：合同负债下降反映的是渠道模式转型，而非终端需求下滑

更重要的是，**茅台经营活动现金流并未恶化**——269.10亿经营现金流，与净利润高度匹配。如果需求真的崩塌，现金流会先于合同负债恶化。

### 4.3 “A股价王被超越，象征意义重大”

**反驳：** 源杰科技涨到1766元，但它一年营收多少？利润多少？市值多少？源杰科技是半导体公司，与茅台完全不同的行业属性。

“股王”称号本就像一场马拉松中的“领跑者”标签——长期来看，谁跑得稳、跑得久比谁某一段冲刺快更重要。茅台过去20年累计回报超过300倍，源杰科技能否维持它的股价高度还是个未知数。

**与其追逐“新王”的短期热度，不如选择“王中之王”的长期稳健。**

### 4.4 “年轻人不喝白酒，茅台没有未来”

**反驳：** 这是最老生常谈却最站不住脚的观点。

- **消费场景决定需求**：茅台的核心消费场景是商务宴请、送礼、收藏，而非年轻人的夜店、聚会
- **消费群体演化**：现在的年轻人会变老、会进入管理层、会成为商务宴请的主角
- **数据说话**：茅台2024年直销收入中，i茅台平台用户年龄结构显示，25-35岁用户占比已达30%以上
- **收藏属性**：茅台具备金融属性，与“喝”无关的消费（收藏、投资、礼品）同样创造需求

## 五、从历史经验教训中学习

### 5.1 2013-2014年：深度调整期的教训

当时茅台PE跌至10倍以下，市场认为“三公消费受限后茅台将沦为普通酒企”。结果呢？茅台通过拓展商务消费和个人消费，实现了营收和利润的持续增长，股价在随后五年涨了10倍。

**教训：不要在恐慌中被情绪主导，当优秀公司被短期困难低估时，恰恰是长期布局的最佳时机。**

### 5.2 2021-2024年：估值泡沫的反思

茅台PE在2021年达到60倍以上，那时的乐观情绪和今天一样极端。但从2600元跌到1200元的过程中，业绩从未下滑——茅台2021-2024年营收增长了约40%，净利润增长了约50%。

**教训：股价下跌不代表基本面恶化，有时只是估值回归。反过来，当前20倍PE的悲观定价，也不是基本面崩溃的证据。**

### 5.3 当前应该吸取的教训

**不要犯两个极端错误：**
1. **不要因为短期利空就全盘否定长期价值**——合同负债下降、增速放缓都是转型阵痛
2. **不要忽视估值极端压缩的机会**——20倍PE的茅台，历史上要么是买入点，要么是崩盘起点（但茅台从未崩盘）

## 六、综合结论：看涨理由充分

回到开头的问题：当前的价格是机会还是陷阱？

我的判断是：**这是一个近五年来看涨逻辑最清晰、估值最便宜、安全边际最厚的布局时机。**

为什么？
1. **基本面极其扎实**：毛利率90%、净利率52%、负债率12%、现金流充沛
2. **估值处于历史底部**：PE 20倍，是过去十年的最低10%分位
3. **负面因素被过度定价**：合同负债下降是渠道转型而非需求崩塌，增速放缓是体量自然规律
4. **积极因素被忽视**：回购、分红提升、超卖技术信号、渠道改革红利
5. **历史经验支持**：每次茅台遭遇悲观情绪、估值极端压缩后，都带来重大投资机会

**看跌方可能告诉你“这次不一样”，但我会说——茅台酒的味道不会变，品牌价值不会变，客户的需求不会消失，而市场情绪终将回归理性。**

当市场最悲观的时候，往往是最值得乐观的时候。贵州茅台当前1,342元的价格，在我看来不是终点，而是新一轮价值发现的起点。

**你愿意在别人恐惧时贪婪，还是在贪婪时被收割？**
