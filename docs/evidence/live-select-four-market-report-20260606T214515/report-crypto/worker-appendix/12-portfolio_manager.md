### 动作约束

**决策理由**：
1.  **最强证据与逻辑一致性**：决定核心基于已验证的下降趋势和MACD空头动能增强。这是当前所有可用数据中信号最明确、逻辑最直接的证据。**看跌观点在此数据环境下拥有更坚固的支撑**。
2.  **看涨逻辑不可靠**：极度超卖指标（RSI 15.15）是看涨的唯一论据，但其可靠性已被上游报告明确指出“在强势下跌趋势中可能长期钝化，并非可靠的反转信号”。缺乏衍生品数据验证的“轧空”或“技术性反弹”是未经验证的假设。
3.  **数据缺口的影响**：衍生品数据的缺失，导致我们无法评估在跌破59128.59美元支撑时，可能因清算级联而引发的下跌加速风险。**此缺口加剧了看跌风险，而非提供了看涨机会**。保守派将缺口视为“不可行动”，中性派将其视为“仓位约束”，均未抓住核心：**缺口本身是看跌逻辑的强化项，因为它放大了潜在的下行速度与幅度**。这个判断逻辑符合《交易员反思》中提到的“不要交易期望，交易已知结构和触发条件”。

**调整后的交易员计划（基于现有数据缺口）：**
*   **入场触发**：等待价格**有效跌破**近期低点 **59128.59 美元**。这是由价格行为验证的唯一客观入场信号。激进分析师将此作为赌注，我将其作为唯一可执行的条件。
*   **目标区间**：下方无成交量数据支撑，目标区间为条件化推演。
    *   **目标1 (观察区)**：58500 - 59000 美元（跌破 59128.59 后的初步观察区间）。
    *   **目标2 (基准)**：57500 - 58500 美元（假设趋势加速，无支撑下的自然延伸区域）。
*   **失效位/止损**：**61500 美元**。这是基于布林带下轨（60891美元）和近期盘整区间上沿的技术性止损，比交易员原先的64000美元更紧，以控制风险。若价格反弹站上此位，看跌结构减弱。
*   **仓位与杠杆**：
    *   **现货持有者**：立即减仓当前现货仓位的 **30%-50%**。
    *   **做空操作**（仅限有条件）：触发入场条件后，仅用总资金的 **1%-2%**（而非激进派的5%）配合 **1倍杠杆**（而非2倍）试空。这采纳了中性分析师的建议，将数据缺口对仓位规模的约束发挥到极致。
*   **最大风险边界**：任何做空仓位的总亏损不得超过总资金的 **0.5%**。1倍杠杆、1%的仓位，止损位约在入场价上方1.5%，亏损风险可控。
*   **分批执行**：不执行一次性开仓。跌破59128.59后初始仓位为1%。若价格进一步跌破58000美元，可在确认成交量和空头动能后，再加仓至总资金2%，止损移至59500美元。
*   **跟踪条件**：价格跌破59128.59后，需观察成交量是否同步放大。若缩量下跌，警惕假跌破。

**需要持续跟踪的条件**：待衍生品数据恢复时，需立即评估**资金费率**和**清算密集区**。若资金费率负值扩大且下方有大量空头清算柱，说明市场过于拥挤，可能引发轧空，此时应立即平仓所有空头头寸，并将此事件记录为《交易员反思》中“忽略拥挤度”的教训。需持续跟踪的还有：成交量、价格在59128.59美元处的收盘行为。
