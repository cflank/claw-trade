### 3.5 数据缺口对投资判断的综合影响

基本面资料的完全缺失限制了投资判断的多个维度：

1. **基本面无已知支撑被低估**：看涨逻辑无法借助网络采用、哈希率新高、持有者行为或减半效应等叙事来强化。
