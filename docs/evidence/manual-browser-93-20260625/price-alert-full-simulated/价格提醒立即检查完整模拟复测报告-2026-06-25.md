# 价格提醒立即检查完整模拟复测报告

测试日期：2026-06-25
测试对象：价格提醒“立即检查”
执行方式：真实 Windows Chrome + 本次临时模拟报价
代码修改：无。模拟报价文件放在 `/tmp/claw-price-alert-mock/sitecustomize.py`，只影响本次启动的 UI 进程，不进入仓库。

## 结论

这项复测在“模拟报价”条件下通过。

之前看到的问题是：能看到新的 scan run id，但报价还是“暂无报价”，也没有触发成功或通知回执。
本次复测证明：只要报价函数返回有效报价，价格提醒可以完整走到触发成功，并在页面显示报价和通知结果。

同时需要把概念说清楚：

| 名称 | 实际含义 | 本次结论 |
| --- | --- | --- |
| scan run id | 后台按 bucket 扫描时产生的扫描编号 | 扫桶链路会产生 |
| 立即检查 | 用户点单条提醒的“立即检查”按钮 | 会触发报价检查和通知回执，但不会生成 scan run id |
| 通知回执 | 提醒触发后记录的通知结果和去重 key | 立即检查链路会产生 |

所以，“立即检查能产生新的 scan run id”这句话不准确。scan run id 属于后台扫桶；立即检查本身记录的是报价、触发状态、通知去重 key 和通知结果。
