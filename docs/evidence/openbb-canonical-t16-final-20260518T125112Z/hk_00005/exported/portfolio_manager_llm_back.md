- **流动性**：`00005.HK` 是蓝筹股，日均成交额通常在10亿以上，流动性充裕。138.50附近的挂单可以顺利成交。执行时，需确认过去5分钟市场不是VCM触发后的极端波动期。

### 4. 从过去错误中学习

我清楚的记得，在202X年我曾重仓一只同样持续回购的香港银行股。当股价跌破MA20时，我选择相信管理层回购，结果股价在随后的三个月内下跌了15%。那次教训的核心在于：**我混淆了“公司内在价值”和“市场短期定价”。** 回购是内在价值的体现，但市场在下跌趋势中，会忽略任何利好，直到价格找到新的平衡。

**这次，我修正了错误：**
- **不再与趋势对抗**：在空头趋势明确时，任何“历史低估”或“管理层信心”都不能成为买入或持有的理由。
- **重视信号共振**：单一信号（如回购）不足以对抗多周期、多指标的共振看跌信号。
- **果断执行**：在方向明确时，不要寻找“更便宜”的入场点（如等待反弹），而应在确认后立即行动，避免错失最佳时机。
