## 一、公司经营与业务质量分析

汇丰控股有限公司（00005.HK）是全球最大的银行及金融服务机构之一，总部位于伦敦，业务网络覆盖欧洲、亚洲、中东、非洲及美洲。集团通过四大环球业务板块运营：财富管理及个人银行（WPB）、工商金融（CMB）、环球银行及市场（GBM）以及企业中心。

汇丰的核心战略近年来持续聚焦亚洲市场，尤其是中国内地、香港及东盟地区，凭借其国际网络连接能力，在跨境贸易融资、财富管理及环球资本市场业务中占有显著竞争地位。集团收入结构以净利息收入为主，同时手续费及佣金收入贡献稳定；利润质量受信贷减值拨备、利率环境及地缘经济波动影响较大。

**现金流方面**：作为大型银行集团，汇丰经营活动现金流通常保持充裕，自由现金流与派息政策密切相关。负债结构以客户存款及同业拆借为主，资本充足率需满足监管要求，杠杆水平受巴塞尔协议框架约束。
