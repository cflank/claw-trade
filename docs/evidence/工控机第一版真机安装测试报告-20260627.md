## 已修复问题

- `tar -tf | head` 在 `pipefail` 下触发 `SIGPIPE`，导致安装脚本提前退出；已改为 `awk` 读取 tar 顶层目录。
- 目标机无 MongoDB 时历史数据恢复失败；已把 MongoDB runtime 放入软件包，安装脚本会在没有可用 `127.0.0.1:27017` 时自动启动本地 MongoDB。
- release/shared 归属 `clawtrade` 导致普通用户启动失败；厂家测试安装改为安装用户拥有 release/shared。
- OpenViking 缺默认配置导致 control runtime 启动失败；已由启动脚本生成本地 `ov.conf`。
- OpenClaw 缺运行依赖导致 gateway 启动失败；已把 OpenClaw runtime node 依赖闭包打入软件包。
- claw-trade OpenClaw 插件找不到 `third_party/openclaw/dist/plugin-sdk`；已在运行资产目录创建兼容链接。
- UI 默认只绑定 `127.0.0.1`，局域网打不开；已改为默认绑定 `0.0.0.0`。
