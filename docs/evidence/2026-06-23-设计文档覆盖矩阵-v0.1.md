## 7. 注意事项

这 62 个数字是**模块级功能点统计数**，不是：

- 用户故事数
- API 数
- 页面控件数
- 代码函数数

它的优点是：

- 可复查
- 可落到设计文档章节
- 能稳定比较“本轮测了多少”

它的局限是：

- 一个功能点内部可能还包含多个子行为
- 所以“62”不是产品真实交互细节的最细粒度上限
