### 1. 投资建议: **卖出**

基于对贵州茅台（600519.SH）当前基本面、技术面及宏观环境的综合分析，当前风险收益比极差。尽管公司品牌护城河深厚，但面临多个史无前例的结构性逆风，且估值尚未完全反映这些风险。建议投资者立即采取行动，**卖出**全部或绝大部分持仓（若重仓，至少减持70%）。

### 2. 目标价位: ¥1,050 - ¥1,224 (3-6个月)

- **基准目标价 (3-6个月): ¥1,224** (基于2026年EPS约¥68元，给予18倍PE估值。这反映了市场对增速中枢下移至6%的合理定价，而非恐慌性抛售。)
- **极端悲观目标价 (3-6个月): ¥1,050** (若合同负债持续恶化、批价跌破2000元，PE可能下杀至15倍历史极端低位，对应EPS约¥70元。)
- **短期技术目标 (1个月): ¥1,280 - ¥1,350** (超卖反弹可能测试该区间，但属于卖出窗口而非买入机会。)

### 3. 置信度: 0.75 (较高)

**理由**: 看跌论据建立在**可验证、可量化**的结构性变化之上，而非简单的周期判断。人口、商务场景、金融属性及合同负债数据的断崖式下跌，提供了明确的卖出信号，置信度较高。

### 4. 风险评分: 0.65 (中等偏高)

**理由**: 
- **下行风险**: 主要来自估值重构（从30倍PE向15-18倍迁移）和基本面加速恶化（批价跌破2000引发库存踩踏）。这是当前的主要风险。
- **上行风险**: 主要来自政策强刺激（如大规模消费券、降息超预期）或公司超预期提价。但这些可能性在当前环境下较低。
- 风险评分中等偏高，并非极致高风险，因为品牌价值依然存在且股价已大幅下跌，但**当前下行空间（15-25%）显著大于上行空间（10-15%）**。

### 5. 详细推理

#### 看跌逻辑的核心：四个结构性变化 + 一个渠道冻结信号

1.  **人口结构“死穴”**：白酒消费主力（35-55岁男性）加速减少，这是第一次出现的**永久性需求萎缩**，而非周期性波动。
2.  **商务消费“冰川期”**：“过紧日子”政策已从临时措施变为制度性安排，高端餐饮连续三年下滑，商务宴请场景遭遇永久性压缩。
3.  **金融属性“达摩克利斯之剑”**：批价从2700元跌至2400元，若跌破2000元心理关口，将引爆巨大的投机库存，造成价格螺旋式下跌。茅台从未经历过“金融去杠杆”。
4.  **代际断层“看不见的伤”**：35岁以下消费者白酒购买比例下降12个百分点，品牌再强也挡不住客户基数的自然萎缩。
5.  **合同负债“断崖”**：2026Q1合同负债从120亿暴跌至42亿（-65%），这**不是**简单的会计调整，而是**经销商打款意愿崩溃**的直接证据。公司甚至需要借钱给经销商进货，这是典型的“渠道失血”信号。

#### 估值重构：20倍PE不是底部，是合理值

- 看涨方常提“20倍PE是历史底部”。但需对比全球：
    - 雀巢（增速4-5%）：PE 18-22倍
    - 可口可乐（增速3-4%）：PE 20-25倍
    - 茅台（未来合理增速6%）：PE **合理估值应为15-18倍**。
- 当前20倍PE对应的是**增速中枢下移后的合理估值**，而非低估。若市场认识到增长模式的永久性改变，PE中枢下移是必然的。

#### 技术面：空头趋势明确，无底部信号

- **均线系统**：MA5 < MA10 < MA20 < MA60，**标准空头排列**，没有任何收敛迹象。
- **MACD**：死叉且负值柱体（-6.76）仍在扩大，空头动能持续释放。
- **RSI(6)**：17.47，严重超卖。但历史多次证明，超卖不等于底部，尤其在趋势下跌初期，超卖后可以继续超卖。

综合以上，**卖出**是当前最理性、风险收益比最优的选择。等待合同负债企稳、批价见底、估值消化到位（PE 15-18倍）后再重新评估。
