# 贵州茅台（600519.SH）基本面分析报告

**报告基准日：2026年5月14日** | **货币单位：人民币（¥）**

---

## 一、公司经营与财务质量分析

### 1.1 盈利能力：极致高毛利、高净利率的标杆

贵州茅台2026年一季度（截至2026年3月31日）实现营业收入 **53.91亿元**，净利润 **28.15亿元**，净利率高达 **52.22%**，毛利率达 **89.76%**。这一毛利率水平在全球消费品行业中处于绝对领先地位，充分体现了茅台酒作为高端白酒的强定价权与品牌护城河。

- **毛利率 89.76%**：成本端占比极低，产品溢价能力极强，原材料（高粱、小麦等）波动对利润影响微乎其微。
- **净利率 52.22%**：在扣除销售、管理、税费等费用后依然保留超一半的收入为净利润，体现出极优的费用控制与税务结构。

### 1.2 现金流质量：利润"含金量"高

报告期内，经营活动现金净流入为 **26.91亿元**，与净利润28.15亿元的比值（即"净现比"）约为 **0.96**，接近1:1。这说明茅台的利润几乎全部以真实现金形式实现，不存在大量应收账款积压问题——这与其"先款后货"的销售模式高度一致。

### 1.3 资产负债结构与财务安全

- **资产负债率仅 12.12%**：这是一个极低的杠杆水平，公司几乎无有息负债压力，财务安全性极高。
- **ROE（净资产收益率）10.57%**：以一季度数据年化估算，全年ROE约在30%-35%区间（过往茅台常年ROE在30%左右），显示出极强的股东回报能力。
- **ROA（总资产收益率）12.00%**：资产运用效率卓越，每一元资产可创造0.12元净利润。

> **小结**：贵州茅台的基本面核心特征可归纳为"三高一低"——高毛利率、高净利率、高现金流质量、低资产负债率。这是A股市场中极为稀缺的优质资产质地。

## 二、估值分析

### 2.1 当前估值水平（截至2026年5月14日）

| 指标 | 数据 |
|---|---|
| 收盘价 | ¥1,342.17/股 |
| 总市值 | ≈ ¥1.68万亿 |
| PE（TTM） | **20.32倍** |
| PB（市净率） | **6.20倍** |
| 每股收益（报告期EPS） | ¥21.76（2026Q1） |

### 2.2 估值位置判断

**PE 20.32倍**是茅台近五年估值区间（约25-60倍）的偏低水平。历史来看，茅台的PE中枢大约在30-35倍（牛市高点可达50-60倍，2022-2023年低迷期也曾在25-30倍附近）。当前20倍出头的水平，处于近年来的估值低位区域。

**PB 6.20倍**，考虑到茅台12%的负债率和超强盈利能力，这一PB水平在当前利率下行环境中具备一定吸引力。

**估值偏低的核心逻辑**：
1. 宏观经济及消费预期偏弱压制板块整体估值；
2. 白酒行业进入"存量竞争"阶段，市场对行业增速放缓存在担忧；
3. 茅台当前PE已经低于其过去5年的历史中位数，可能隐含了较多悲观预期。

## 三、合理价格区间与情景假设

### 3.1 情景假设说明

由于工具数据包未提供TTM EPS（每股收益按全年口径折算）、历史PE分位数及行业估值中位数，以下价格区间的测算基于分析师的合理情景假设，并非数据源直接提供的事实，仅供参考。

**假设前提**：
- 以2025年全年EPS（市场一致预期约¥65-70）作为基准进行测算，而非单季EPS直接年化（Q1 EPS为¥21.76，存在季节性波动）。
- 取行业中性的PE中枢 **28-33倍**作为合理估值区间。

### 3.2 测算结果

| 情景 | 假设EPS（全年） | 假设PE | 对应股价 |
|---|---|---|---|
| 悲观情景 | ¥65 | 22倍 | ≈ ¥1,430 |
| 中性偏保守 | ¥68 | 28倍 | ≈ ¥1,904 |
| 中性偏积极 | ¥68 | 33倍 | ≈ ¥2,244 |
| 乐观情景 | ¥70 | 38倍 | ≈ ¥2,660 |

**当前股价¥1,342.17**，低于上述所有情景下的合理估值下限（悲观情景¥1,430），说明市场可能已过度定价了茅台面临的负面因素。

> **重要提示**：以上测算结果基于分析师情景假设，EPS与PE均非数据源直接提供的事实，投资者应结合自身判断使用。

## 四、投资建议

### 综合评级：**买入**

**核心逻辑**：

1. **基本面确定性极强**：茅台拥有A股最深的品牌护城河、最强的现金流造血能力和最低的财务风险。即便在消费疲软的大环境下，其收入与利润的稳定性仍远优于绝大多数企业。

2. **估值已进入历史低位区间**：PE 20.32倍处于近年来的底部区域，向下空间有限，向上修复弹性较大。

3. **潜在催化因素**：若宏观消费预期改善、白酒行业库存周期触底、或茅台通过提价/非标放量等方式增厚利润，估值修复空间可观。

## 五、数据限制与风险提示

1. **数据口径冲突说明**：本报告数据源中，tushake与akshare在营业收入、净利润、EPS及ROE字段存在明显冲突（akshare返回的营业收入仅为数亿元，显著低于实际水平）。本报告已采用tushare数据作为主要依据，因其数据规模与茅台公开披露的一季度报告金额一致。

2. **估值分析限制**：当前数据包未提供以下关键信息——（a）TTM EPS（按过去12个月合计）；（b）历史PE/PB分位数；（c）行业平均估值中位数；（d）DCF模型所需参数（自由现金流、加权平均资本成本等）。因此估值位置判断存在一定主观性。

3. **价格测算非事实承诺**：第三部分合理价格区间的测算基于分析师情景假设，EPS采用市场一致预期范围（非数据源直接提供），PE采用行业历史中枢判断。该测算不构成对未来股价的承诺或保证。

4. **时效性说明**：本报告基于截至2026年5月14日的数据编制，财务数据截至2026年3月31日（一季度报告），尚未覆盖2025年全年正式年报及2026年中期业绩。

5. **本报告不构成投资建议的最终依据**，投资者应结合自身风险承受能力、持仓情况及市场最新变化独立做出决策。
