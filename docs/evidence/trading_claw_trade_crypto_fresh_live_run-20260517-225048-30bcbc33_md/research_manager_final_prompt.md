## 1. 项目定位与需求真实性

Bitcoin 是全球首个去中心化数字货币网络，其核心定位为**点对点电子现金系统**与**数字价值存储**。解决的问题包括：传统金融体系中第三方中介的信任成本、跨境支付的高费用与低效率、以及主权货币的长期贬值风险。

**需求真实性判断：** Bitcoin 的需求来源于以下几个维度——（1）全球范围内对非主权价值储存手段的持续需求，尤其在通胀较高或资本管制严格的经济体中；（2）机构与零售投资者将 BTC 视为"数字黄金"，作为资产组合中的对冲配置；（3）跨境支付与资金转移场景中的实用需求。这些需求在过去十余年中持续存在并呈现增长趋势，具有真实性和可持续性。但需注意，当前市场中投机性交易仍占据主导地位，短期价格波动大幅超过其支付或储值属性的实际使用增速。
