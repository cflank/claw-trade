# 贵州茅台（600519.SH）基本面投资报告

## 一、公司经营与财务质量分析

### 核心盈利指标
根据系统获取的财务数据，贵州茅台当前净资产收益率（ROE）为 **10.57%**。这一水平在A股消费品龙头中处于较高位置。贵州茅台的核心竞争力在于其品牌护城河极深的茅台酒产品线，依托稀缺的酿造资源、不可复制的产区环境和强大的品牌溢价能力，长期保持着极其稳定的高盈利水平。

### 资产负债结构
由于本次资料包中利润表、现金流量表、资产负债表的具体明细条目未完整推送，以下基于已知事实做定性分析：
- 贵州茅台作为典型的"现金奶牛"企业，账上货币资金极其充裕，几乎没有有息负债，属于净现金公司。
- 预收款项（合同负债）常年维持高位，体现下游经销商对茅台酒的持续强需求，经销商提前打款意愿强烈。

### 现金流质量
茅台经营活动现金流通常远高于净利润，盈利的现金实现能力极强。虽然本次没有获得现金流具体数字，但这是茅台历史财务中最为稳定的特征之一，属于行业共识。

## 二、估值分析

| 指标 | 当前数值 | 历史区间参考 |
|------|---------|-------------|
| 市盈率（PE） | **20.03 倍** | 历史PE中枢约30-35倍 |
| 市净率（PB） | **6.12 倍** | 高ROE支撑下的正常偏高区间 |

**估值位置判断：**

当前 PE ≈ 20 倍，处于贵州茅台近5年估值区间的 **偏低位置**。回顾历史：
- 2021年核心资产牛市时，茅台PE一度突破60-70倍。
- 2022-2023年受消费疲软、外资流出等影响，PE回落至25-35倍区间。
- 当前约20倍PE，已低于过去10年历史均值（约30倍），处于近五年的下沿区域。

PB为6.12倍，由高ROE（10.57%）支撑，属于合理偏低估水平。理论上，如果ROE稳定在10%以上，PB在6倍附近对应的是市场对净资产溢价能力的合理认可。

## 四、投资建议

### 建议：买入

**核心逻辑：**
1. PE ≈ 20倍处于近五年历史底部区间，远低于历史中枢30倍以上，估值具备较高安全边际。
2. ROE仍维持在10.57%的健康水平，说明公司盈利能力并未发生根本性恶化。
3. 贵州茅台作为中国高端白酒的绝对龙头，品牌壁垒、渠道控制力和定价权在消费品行业中几乎无可匹敌，具备穿越周期的能力。
4. 当前市场对消费的悲观情绪已较大程度体现在股价中，一旦消费数据出现边际改善，估值修复弹性较大。
