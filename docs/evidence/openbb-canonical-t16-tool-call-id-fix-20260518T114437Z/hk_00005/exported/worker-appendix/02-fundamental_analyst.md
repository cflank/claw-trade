# 汇丰控股（00005.HK）基本面研究报告

## 一、公司经营与业务质量分析

汇丰控股有限公司（00005.HK）是香港交易所上市的国际化银行集团，总部位于伦敦，业务覆盖全球60多个国家和地区，是香港三大发钞行之一。主要业务板块包括财富管理及个人银行（WPB）、工商金融（CMB）、环球银行及资本市场（GBM）以及企业中心（Corporate Centre）。收入来源高度多元化，涵盖利息净收入、手续费及佣金收入、交易业务收入以及保险业务收入等。作为系统重要性银行，其资产负债结构以存贷款业务为核心，经营现金流主要来自利息和手续费收入，具备较强的现金生成能力。

## 五、港股语境下的投资逻辑

- **市场与流动性**：汇丰控股是香港交易所蓝筹股，恒生指数成分股，日均成交额居港股前列，流动性充裕。
- **每手股数**：港股常规每手400股（以汇丰控股为例），需注意交易规则。
- **港股通/南向资金**：汇丰控股为港股通标的，内地投资者可通过南向渠道交易，南向资金流向对股价有一定边际影响。
- **双重上市情况**：汇丰控股同时在伦敦证券交易所（LSE）和香港交易所（HKEX）上市，并可在美国以ADR形式交易，存在跨市场价差和套利机制。
- **红筹/中概回港**：汇丰控股为英资银行，非红筹或中概回港股，此条不适用。
