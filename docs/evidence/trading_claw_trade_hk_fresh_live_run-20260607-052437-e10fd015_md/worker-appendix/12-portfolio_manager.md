## 二、决策理由：支持**卖出**

### 决定性论据——逻辑严谨性压倒性胜出

**1. 关键证据空白的致命性**

激进分析师的整个“结构性重估”叙事建立在一个未经核实的假设上：2025年Non-IFRS净利润约2400亿。但综合报告明确声明“工具返回的财务数据完全缺失”。在投资决策中，**一个无法验证的核心假设就是致命的逻辑漏洞**。保守分析师正确地抓住这一点，将其定义为“信仰型投资”而非理性分析。

**2. 技术面风险信号的一致性**

- **RSI 50.18**：这不是“上涨动能刚刚启动”，而是在价格已上涨14%（偏离MA20）后，动能却不温不火。这是典型的**价格与动能背离**。
- **高位横盘510-518**：成交量从1300万放至1900万，但价格无法突破。这是多空分歧加剧的表现，而非“洗盘结束”。
- **偏离均线11%-14%**：在没有强劲基本面催化剂的情况下，均值回归是大概率事件。

**3. “反思”教训的正确运用**

激进分析师引用2021年顶部教训——“不要在恐慌时卖出”，但恰恰混淆了场景：
- 2021年初顶部：PE 35倍，市值7万亿，情绪亢奋，RSI>70
- 当前：PE假设值17倍，市值4万亿，RSI 50，情绪中性
- **关键区别**：顶部特征是“情绪亢奋+估值泡沫”，底部特征是“情绪绝望+估值极低”。当前既不是顶部也不是底部，而是**中性偏高的技术位**。

正确的历史教训是：**2018年我们在底部恐慌卖出是错误的，但2021年在顶部贪婪持有同样错误**。现在的信号更接近2021年顶部的前奏——价格已大幅上涨（相对年初），而驱动上涨的催化剂（南向资金、回购数据）正面临“数据空白”。

**4. 风险回报比的数学结论**

基于可验证的技术指标：
- **下行风险**：455-465港币（-11%至-13%），概率高（技术面强信号）
- **上行空间**：525港币（+3%），概率低（缺乏催化剂）
- **预期值**：-11% × 0.7 + 3% × 0.3 = -7.1%（负期望值）

持有不是中性选项，而是**在负期望值的赌局中维持仓位**。
