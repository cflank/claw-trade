# 贵州茅台（600519.SH）基本面分析报告

## 一、公司经营与财务质量分析

### 1.1 收入与利润

根据最新财报数据，贵州茅台2025年全年实现营业收入**1,688.38亿元**，同比增长约11.5%（基于2024年全年数据推算），归属于母公司净利润**823.20亿元**，净利率高达48.8%，盈利能力在A股市场中稳居顶级水平。

2026年第一季度（截至2026-03-31），公司实现营业收入**539.09亿元**，净利润**272.43亿元**，单季净利率仍保持在**50.5%**的高位，营收与利润均创下同期历史新高。

**增长趋势**：
| 报告期 | 营业收入（亿元） | 净利润（亿元） | 每股收益（元） |
|--------|:-----------:|:-----------:|:----------:|
| 2025Q1 | 514.43 | 268.47 | 21.38 |
| 2025H1 | 893.89 | 454.03 | 36.18 |
| 2025前三季 | 1,284.54 | 646.27 | 51.53 |
| 2025全年 | 1,688.38 | 823.20 | 65.66 |
| 2026Q1 | 539.09 | 272.43 | 21.76 |

2026年一季度营收同比2025年一季度增长约4.8%，净利润同比增长约1.5%，增速有所放缓，但绝对利润规模依然强劲。

### 1.2 毛利率与盈利能力

公司毛利率保持在**91%以上**的极高水平：
- 2025全年毛利率：**91.18%**
- 2026Q1毛利率：**89.76%**，略有回落但仍属顶级

净资产收益率（ROE）：
- 2025全年ROE：**32.53%**（按加权口径约34.46%）
- 2026Q1年化ROE仍处在高位区间

总资产收益率（ROA）：
- 2025全年ROA：**28.31%**
- 2026Q1 ROA：9.03%（单季年化约36%以上）

茅台凭借茅台酒的品牌溢价与稀缺性，长期维持超高毛利率和净资产收益率，是中国消费品行业中护城河最深厚的公司之一。

### 1.3 资产负债结构

| 指标 | 2025-06-30 | 2025-12-31 | 2026-03-31 |
|------|:--------:|:--------:|:--------:|
| 总资产（亿元） | 2,922.58 | 3,038.35 | 3,199.19 |
| 总负债（亿元） | 431.22 | 498.76 | 387.83 |
| 资产负债率 | 14.75% | **16.42%** | **12.12%** |

公司资产负债率仅约12%-16%，几乎没有有息负债压力，财务状况极为稳健。2026Q1总资产突破3,199亿元，负债率降至12.12%，进一步优化。

### 1.4 现金流质量

- 2025全年经营活动现金流净额：**615.22亿元**
- 2026Q1经营活动现金流净额：**269.10亿元**

现金流与净利润高度匹配，经营活动现金流/净利润比例保持在1.0以上，利润"含金量"极高，反映出茅台强大的回款能力和经销商预收款模式的优势。

## 二、估值分析

### 2.1 当前估值水平（截至2026-06-15）

| 估值指标 | 数值 |
|---------|:---:|
| 市盈率（PE-TTM） | **19.30倍** |

| 市销率（PS） | **9.41倍** |
| 总市值 | **1.59万亿元** |

### 2.2 PE估值位置判断

基于2025年全年EPS **65.66元/股**计算的PE为19.30倍；基于2026年Q1单季EPS **21.76元/股**（年化约87元/股）测算的前瞻PE约为18.3倍。

**历史区间参考**：茅台过去5年的PE运行区间大约在25-60倍之间，当前19-20倍的PE处于近5-10年的**历史低位区间**，已显著低于历史中枢（约30-35倍）。这一估值水平主要反映了：
- 市场对白酒行业整体需求放缓的担忧
- 宏观消费环境的不确定性
- 机构重仓股调整带来的资金面压力

### 2.3 PEG分析

以2025年归母净利润823.20亿元为基数，假设未来3年净利润复合增速在8%-12%之间：
- 当前PE（19.3倍）/ 增速（10%）≈ **PEG约1.93**
- 若增速降至8%，PEG约2.41
- 若考虑2026年Q1增速放缓的趋势，PEG处于1.9-2.4区间

从绝对PEG角度看，当前估值不算极度便宜，但对比茅台历史PEG常年在3-5倍的水平，当前已进入相对合理甚至低估的区域。

**综合判断**：当前股价处于**保守情景下方**，低于中性情景的合理区间下沿，具备一定的安全边际。

## 四、投资建议

### 建议：买入

**核心逻辑**：
1. **估值处于历史底部**：PE 19.3倍是近十年最低区间，已经充分消化了行业增速放缓的悲观预期。
2. **超强护城河不变**：茅台品牌壁垒、稀缺性、定价权等核心竞争力未受实质性削弱。
3. **财务质量顶级**：超过90%的毛利率、30%+的ROE、极低负债率、充沛现金流，在全市场都属于稀缺标的。
4. **分红回报可观**：茅台近年分红比例持续提升，当前股息率已逐步上升至有吸引力水平（按2025年分红方案计算，股息率约2%以上）。

### 关键风险因素

1. **宏观经济下行风险**：白酒消费与宏观经济高度相关，若居民消费持续疲软，高端白酒可能面临量价压力。
2. **行业政策风险**：消费税改革、限制三公消费等政策若趋严，可能冲击行业生态。
3. **批价波动风险**：茅台酒终端批价若持续下行，将影响渠道信心及公司提价空间。
4. **增速放缓超预期**：2026Q1营收增速已降至个位数，若后续季度继续降速，业绩不及预期可能引发估值进一步压缩。
5. **管理层与渠道改革不确定性**：直销占比提升已推动利润增长，但进一步优化的空间和效果需持续跟踪。

## 五、数据限制与风险提示

- **数据截至日期**：本报告使用的财务数据最新截止于2026年3月31日（2026年一季报），估值数据截至2026年6月15日。后续财务数据尚未披露，存在滞后性。
- **口径说明**：毛利率数据存在两套口径。精细口径显示2025年毛利率为89.76%-91.97%区间，整体口径显示约91.18%，差异源于计算方式不同（是否含消费税等），但不改变超高毛利率的结论。
- **现金流数据**：仅获取了经营活动现金流净额的汇总值，未细分投资与筹资现金流，可能影响对整体现金流结构的完整判断。
- **估值可比性**：PE/PB等历史分位数据因数据样本有限（仅覆盖约1年日频数据），无法进行精确的历史百分位计算，历史中枢判断基于长期跟踪经验。
- **合理价格区间**：为基于公开数据的模型估算值，受假设条件（EPS增速、目标PE倍数）影响较大，不构成精确投资建议，仅供参考。
- 本报告不构成任何形式的投资承诺，股市有风险，投资需谨慎。
