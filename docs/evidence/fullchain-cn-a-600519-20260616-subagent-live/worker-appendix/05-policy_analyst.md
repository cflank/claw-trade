## 四、传导逻辑分析

### 核心传导链一：控股股东减持 → 投资者信心 → 估值承压

```
控股股东及一致行动人减持预披露
          ↓
市场解读为重要股东对当前估值或未来预期的审慎信号
          ↓
短期风险偏好收窄，资金倾向减仓或观望
          ↓
对茅台估值（尤其是PE溢价）形成短期压制
          ↓
交易含义：短期偏空，关注减持落地节奏与配额
```

这是当前对茅台最直接、最可验证的政策/公司行为传导链。减持预披露本身并不等于利空兑现（通常在披露后3—6个月内逐步完成），但信号意义明确。

### 传导链二：分红派息 → 股息率 → 价值锚定

```
2025年度分红派息实施
          ↓
确认每股分红金额，计算当前股息率
          ↓
茅台作为核心红利资产的吸引力重新定价
          ↓
长线资金（险资、外资）的配置参考
          ↓
交易含义：对估值提供底部支撑，但不敌短期情绪扰动
```

### 传导链三：宏观政策与消费环境（间接）

```
规范涉企行政执法 + 农村公路建设
          ↓
优化企业预期 + 下沉渠道基础改善
          ↓
消费行业长期经营环境边际改善
          ↓
对茅台渠道拓展、品牌溢价维持形成正贡献
          ↓
交易含义：长期结构性支撑，非短期交易驱动因子
```
