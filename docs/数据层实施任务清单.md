## 1. 执行原则

- 重建新数据层控制核心：统一数据需求、按数据类型的 provider catalog / priority policy、freshness / cache / rate-limit / single-flight gate、Managed HTTP 与 SDK unknown 语义、`/report` data plan、`/select` warehouse check plan、UI provider display decision、failure / data gap 语义、evidence writer / materializer 与 OpenViking 边界。
- 复用底层事实合同：沿用现有 `openbb_*` Mongo collection 常量、`src/claw_trade/data_gateway/store/*`、`MongoRateLimitStore`、`RateLimitPlanMetadata`、attempt/raw/normalized/http evidence 合同、selection store 与 data job evidence 文件事实。
- 入口硬切：`/report` 启用新入口后只能走新数据层；`/select` 启用新仓库检查后旧 selection provider batch 不再参与；UI probe 只产生 probe evidence；价格提醒接入时也走同一数据入口。
- 无 fallback 兜底：新失败不能走旧，旧失败不能走新，不能自动 fallback 成功；失败只能返回缺口、attempt、evidence 或 hard fail。
- 无 mock / stub / fake / skeleton / placeholder success：任务验收必须证明真实代码路径、真实写入合同和真实失败语义；测试替身只能用于单元隔离，不能作为产品成功证据。
- provider 能跑就跑：某个候选失败时记录 attempt / gap / evidence，然后在同一种数据类型下尝试下一个候选；不能把失败、cache hit、shared result、rate limited、cached empty、cooldown skipped 写成远端成功。
- 预下载和运行时按需分层：历史包 / 每日更新只维护批准过的基础仓库数据；真实 `/report`、`/select`、UI probe、价格提醒必须按数据类型、粒度、字段、时间范围和新鲜度先查 Mongo，缺失、过期、字段不足或粒度不匹配时再补 provider 或返回缺口。
- Worker 可见边界：worker 只能看到自然语言资料包、source summary 和缺口摘要；不能看到内部 debug envelope、provider attempt 对象、cache 对象、rate-limit 对象或控制面 checklist。
- Coverage Ledger 机制：实施前生成 ledger，列出所有 DG-*、§5 数据结构、§6 存储边界、§7 模块边界、§8-§10 gate/evidence 规则、§11-§12 函数、§13-§16 市场规则、§17 UI 显示、§18 失败状态、§19 Stop Conditions、§22 Deviation Audit；每一项必须映射到任务 ID，状态只允许 `覆盖` 或 `BLOCKED`。
- Store Contract 机制：任何 Mongo 写入必须先声明现有 collection、writer、reader、ref/hash/integrity marker；禁止新增同义平行主表。若现有表无法承载，必须列为 human-approval stop condition。
- Verification 机制：每个任务给出未来最小可验证命令或检查方式；本清单阶段不运行 live/fresh/provider/UI 验证。OpenClaw/OpenViking/runtime 相关任务必须区分 source test 与 runtime proof。

## 5. Stop Conditions

- 需要新增同义平行 Mongo 主表，或现有 `openbb_*` / selection evidence 文件无法承载。
- 需要 OpenViking 保存 provider cache、限流状态、结构化主仓或外部 provider 调用结果唯一副本。
- 需要 Python 生成、补写、改写或替代 worker/PM 投资结论。
- 需要新失败走旧、旧失败走新，或通过 fallback success 掩盖真实失败。
- 需要把 cache hit、shared result、rate limited、cached empty、cooldown skipped、SDK unknown、evidence write failed 写成远端成功。
- 需要把搜索源、probe、预留配置项或 UI key 填写状态当正式事实源或主链路证据。
- 需要新增总体设计未批准 provider、全局 provider 排名、新市场主链路或新 UI 入口。
- 需要恢复港股/美股 `/select`、历史包下载范围或早前备选历史包。
- 需要把 Crypto 历史包扩大为分钟级长历史、全链上、全社交、全新闻、全事件预期的全量预下载。
- 需要绕开 `MongoRateLimitStore`、`RateLimitPlanMetadata`、现有 attempt/raw/normalized/http evidence 合同。
- 需要放松 truthfulness hard gate，或新增影响报告表达风格的 runtime guard。
- OpenClaw/OpenViking/runtime 行为变更无法按 source test、build/restart、post-restart runtime proof 区分验收。
