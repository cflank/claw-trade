# 2026-06-18

## /select 加密市场实施收尾

- 目标：在现有 `/select` 命令中增加加密市场选币能力，同时保留默认 A 股行为。
- 命令入口：
  - `/select`、`/select 1`、`/select CN_A`、`/select A股` 默认走 A 股。
  - `/select 2`、`/select CRYPTO`、`/select crypto`、`/select 加密` 走加密市场。
  - `refresh` 可与市场参数组合，例如 `/select 2 refresh`。
- 历史数据来源：加密历史数据不是 Mongo；运行读取列式历史仓库 `data/crypto-history-full/normalized-columnar-usdt-only` 下的 Parquet 种子数据。Mongo 只用于目录、证据、manifest 等元数据语义，不作为历史行情行存储。
- 加密范围：现阶段只读 Binance spot USDT 日线，过滤 `dataset=daily_bar`、`market=CRYPTO`、`granularity=daily`、`universe_ref=binance_spot_all_symbols`、`quote_asset=USDT`、`market_segment=spot`。

## 主要实现

- `src/claw_trade/data_gateway/_selection_batch.py`
  - 增加 CRYPTO 列式种子 Parquet 读取路径。
  - CRYPTO 未传日期时解析为列式仓库里的最新可用交易日。
  - 复用现有选股特征构建和候选缓存写入，不新增下载器、导入器、期货逻辑或外部数据源。
  - CRYPTO 数据缺失时返回明确 blocker：`crypto_select_history_missing`。
- `src/claw_trade/data_gateway/selection_api.py`
  - 导出 CRYPTO 交易日解析和通用刷新策略加载接口。
- `src/claw_trade/selection/refresh.py`
  - 刷新调度按市场解析交易日；CRYPTO 不再经过 A 股交易日历。
- `src/claw_trade/selection/controller.py`
  - `/select` 参数支持市场 token。
  - CRYPTO 报告标题和提示语使用“加密市场”“标的”，不写成 A 股或股票语义。
  - USDT 代码解析支持无数字代码，例如 `CUSDT`。
- `src/claw_trade/selection/candidate_cache.py`
  - CRYPTO 候选缓存标题改为 `# 加密市场候选缓存`。
  - 数据质量摘要使用“标准化标的”。
- `src/claw_trade/selection/dispatch.py`
  - 候选池核对支持 USDT 代码，避免 `NEARUSDT`、`CUSDT` 被排除。
- `agents/selection_*/STAGES.yaml`
  - 四个 selection worker 增加已批准 `CRYPTO` profile。
  - strategist/skeptic 暴露 `selection_candidate_cache`；manager/portfolio_manager 不暴露工具。
- `agents/selection_*/prompts/CRYPTO.md`
  - 新增 CRYPTO 中文提示词，明确 spot USDT 边界、不得回退到 A 股、术语使用“标的/价格/代币价格”。
- `docs/加密市场选币设计.md`
  - 中文设计文档，明确列式历史仓库、命令映射、验证口径和不做范围。
- `docs/superpowers/plans/2026-06-17-select-crypto-market.md`
  - 实施计划记录。

## 偏差和限制

- 按 Ponytail 原则复用现有 `_selection_batch.py`，没有新增独立数据网关文件；这是为了少引入抽象和迁移面。

- UI 后端在沙箱内启动新 socket 时遇到 `PermissionError: [Errno 1] Operation not permitted`，已用批准的 escalated 启动完成 API/live 验证。
