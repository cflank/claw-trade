# Output Templates Reference

Rule version: `bb-output-template-skill-v3-process-first`.

Use these templates to keep analysis auditable. Keep reader-facing output in Chinese and explain data quality without copying machine field names.

## Envelope Fields To Preserve

Every analysis should account for:

```text
status
as_of
sources
confidence
data-quality state
warnings
open data gaps
conflicts
next_actions
```

Mapping:

- sources and data time -> data time and data source section
- warnings -> data status or risk notes
- open data gaps -> data gap section, not only prose
- conflicts -> conflict section; never merge into one silent number
- next actions -> next data/review action
- error status -> no full trade plan

## Process-First Rule

The coverage matrix proves that data was checked; it is not the analysis.

For every full market analysis, the primary body must be `指标推导过程`. Each subsection must use this exact reasoning shape:

```text
数据:
推导:
交易作用:
失效:
```

Definitions:

- `数据`: concrete values, levels, counts, states, source paths, sample status, warnings, or missing field paths from the envelope.
- `推导`: why the data is bullish, bearish, neutral, conflicting, or not actionable.
- `交易作用`: support, resistance, trigger, target, invalidation, risk filter, or no-trade filter.
- `失效`: price level, structure break, sample limitation, provider limitation, freshness limit, or missing-domain reason.

Forbidden shortcut:

```text
RSI: 中性；MACD: 偏多；FVG: 直接给交易结论。
```

Required replacement:

```text
RSI / MACD:
数据: 4h RSI 45.2，MACD 柱为正；1d MACD 柱为负。
推导: 4h 有修复，但日线动能尚未确认，因此只能视为短线反弹观察。
交易作用: 作为突破确认的辅助，不是独立入场触发。
失效: 4h 重新跌回关键均线/布林中轨下方，短线修复失效。
```

When FVG has no upstream statistical or execution-mechanism proof, write it as a recorded zone with sample limits, not as support, resistance, target, magnet, or standalone trade reason.

## Mandatory Coverage Matrix

Every market analysis must include this section. Use the first `build_trade_context` envelope. Do not re-query ready domains just to fill prose.

```text
指标覆盖：
| 模块 | 状态 | 结构化路径/数值 | 对结论的影响 |
|---|---|---|---|
| 布林带 | 已引用/可分析/样本限制/缺失/不可用/不适用 | data.technical.timeframes[*].indicators.bollinger_bands_20_2 | ... |
| 维加斯通道 | ... | data.technical.timeframes[*].vegas | ... |
| 双线反转 | ... | data.technical.timeframes[*].patterns.double_line_reversal | ... |
| AMD/SMC | ... | data.technical.timeframes[*].patterns.amd | ... |
| 123 突破 | ... | data.technical.timeframes[*].patterns.rule_123 | ... |
| FVG | ... | data.technical.timeframes[*].patterns.fvg | ... |
| OB 订单块 | ... | data.technical.timeframes[*].patterns.order_block | ... |
| RSI | ... | data.technical.timeframes[*].indicators.rsi14 | ... |
| MACD | ... | data.technical.timeframes[*].indicators.macd_12_26_9 | ... |
| KD | ... | data.technical.timeframes[*].indicators.kd_9_3_3 | ... |
| TD 9/13 | ... | data.technical.timeframes[*].indicators.td_sequential | ... |
| 谐波形态 | ... | data.technical.timeframes[*].patterns.harmonic | ... |
| 交易密集带/成交量分布 | ... | data.technical.timeframes[*].patterns.volume_profile | ... |
| 清算地图 | BTC 用已引用/可分析/样本限制；非 BTC 用不适用 | data.liquidation_map | ... |
| CVD/主动买卖量 | ... | data.derivatives.cvd_proxy 或 data.derivatives.taker_buy_sell | ... |
| 资金费率 | ... | data.derivatives.funding_rates | ... |
| OI/多空比 | ... | data.derivatives.open_interest / long_short_ratio | ... |
| 宏观 | ... | data.macro | ... |
| 链上 | ... | data.onchain | ... |
| AHR999 | ... | data.ahr999 | ... |
```

Status rules:

- `已引用`: field exists and materially affects the conclusion.
- `可分析`: field exists and can support the current analysis, even if it is neutral, low confidence, conflicting, or not decisive.
- `样本限制`: rows exist but the history span, frequency, or sample count is narrower than requested; analyze the returned rows first and state the limitation.
- `缺失/不可用`: field missing, provider failed with no usable rows, or not exposed in the MCP envelope.
- `不适用`: structurally not applicable, for example AHR999 on non-BTC.

If `data.technical.tutorial_coverage` is absent, explicitly write: `coverage matrix missing from MCP output`, lower confidence one level, and list the missing field paths.


Expansion rules:

- OB must mention nearest bullish and bearish zones when both exist near price.
- POC must mention POC, value-area high, and value-area low when available.
- TD Sequential must mention timeframe conflicts instead of treating one timeframe as decisive.
- Harmonic must explicitly say there is no valid harmonic setup when `candidates=[]`.
- FVG must identify whether the nearest gaps are support, target, filled, partially filled, or open.
- Core indicators must compare at least the requested timeframe and one higher timeframe when available.
- Derivatives must distinguish funding, OI, CVD proxy, and long/short account ratio; do not merge them into one sentiment label.
- Macro/on-chain/events/AHR999 are risk filters unless the envelope explicitly supports an actionable trigger.
- If a field is missing, cite the missing path rather than replacing it with a tutorial concept.

## Limited Data-Quality Template

Use when data quality is limited/not reliable or status is error.

```text
当前只能输出有限观察：
- status:
- as_of:
- 可用数据:
- 缺失数据:
- 冲突数据:
- 指标覆盖:
- 可安全推导的内容:
- 不能确认的结论:
- 下一步补数:
- 风险提示:
```

Forbidden in this state:

- full entry/stop/target plan
- high-confidence AMD/FVG/123/rejection conclusion
- liquidation-hunt target without `liquidation_map`
- funding/OI/CVD conclusion without derivatives
