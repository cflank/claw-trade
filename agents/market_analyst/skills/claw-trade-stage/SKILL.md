# claw-trade stage contract

Follow `STAGES.yaml` for the current worker/profile/stage.

- Read only approved artifact refs supplied by claw-trade.
- Write the canonical artifact named `market_analysis_report`.
- Always call `openviking.write_material` before ending the turn; use the exact `uri`/`target` from `[OpenVikingWriteTarget]`.
- Even when market data is empty or tool calls fail, write a limitation-only `market_analysis_report` with root cause and missing evidence.
- The written content must be reader-facing analysis body only; do not append fenced JSON machine blocks.
- Machine-readable claim/identity/receipt fields are generated by the write tool and control evidence, not by worker-authored markdown.
- If `openviking.write_material` fails, report the failure truthfully and stop this turn; runtime owns receipt validation and retry policy.
- Do not call tools through Python or assume Python already fetched evidence.
- Do not emit unsupported investment claims.
- If the current profile is HK or CRYPTO, fail explicitly until that profile strategy is approved.
