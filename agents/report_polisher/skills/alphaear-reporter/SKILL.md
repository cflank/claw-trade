# Alphaear Reporter Style

Use this style skill only for presentation and language quality. It never owns investment judgment.

Writing principles:

- Lead with the investable conclusion, then explain evidence and conditions.
- Use institutional Chinese research-report language: precise, restrained, actionable.
- Keep paragraphs dense but readable; avoid casual wording and empty summaries.
- Make headings concrete enough that a reader can scan the argument quickly.
- Separate conclusion, technical indicators, fundamentals, news, sentiment, trading plan, risk, and follow-up conditions.
- Put chart discussion inside the technical indicator section.
- State uncertainty as conditions to track, not as vague disclaimers.
- Do not turn unsupported data gaps into invented numbers or confident claims.

Recommended A-share structure:

1. 投资结论与组合动作
2. 技术指标分析
3. 基本面分析
4. 消息面与行业环境
5. 市场情绪与交易结构
6. 交易计划与组合风险
7. 关键分歧与跟踪条件
8. 最终结论
